## 2. 기술 선택과 이유

| 선택 | 이유 |
|---|---|
| React 19 + Vite 8 + TypeScript | shadcn/ui의 기준 구성. Vite는 해시가 붙은 정적 파일만 만들고 인라인 스크립트를 넣지 않아 CSP(`script-src 'self'`)와 맞는다 |
| Tailwind CSS v4 + shadcn/ui (radix-nova 프리셋) | 요청대로 버튼·카드·배지·입력·브레드크럼·탭·토글 그룹·팝오버·커맨드·툴팁·알림·스켈레톤·빈 상태를 shadcn 것으로 썼다. 직접 만든 것은 도메인 조합(레포 행, 파일 목록, 코드 보기)뿐 |
| 색 | 앱 디자인 시스템(`docs/ui/design-system.md`)의 브랜드 파랑 `#3366FF`/`#7C9CFF`, 회색 바탕 위 흰 카드, 상태 톤(성공·경고·위험·정보·중립)을 그대로 옮겼다. 배지는 항상 아이콘 + 글자 |
| 글꼴 | 시스템 글꼴(맑은 고딕, Apple SD 고딕 네오 등). 프리셋의 Geist 웹폰트는 뺐다 (APK 크기, 한글 미지원) |
| 라우팅: 직접 만든 해시 라우터 60줄 (`lib/router.ts`) | 서버의 SPA 대체가 `.`이 있는 경로를 404로 보내서 history 라우팅을 못 쓴다(WR-1). wouter의 해시 훅은 쿼리를 해시 밖(`?x#/path`)에 두어 새 탭 링크가 깨지고 경로를 `decodeURI`로 한 번 더 풀어 `%2F` 처리가 애매해서 뺐다. 링크는 평범한 `<a href="#/...">`라 새 탭·뒤로 가기가 그대로 된다 |
| 데이터: `fetch` + 작은 `useApi` 훅 | GET만 있는 읽기 전용이라 TanStack Query는 과하다. 탭이 살아 있는 동안 메모리 캐시 후 매번 재검증 |
| 구문 강조: highlight.js (`lib/common`, 37개 언어) | 파일 보기에서만 동적 import(별도 청크 52KB gzip). 클래스 기반 출력이라 CSP 문제 없음. 256KB 넘는 파일은 강조하지 않는다. Shiki는 WASM·테마 JSON으로 수 MB, Prism은 줄 단위 처리가 비슷하지만 유지보수가 느려져 hljs를 골랐다 |
| Markdown | 코어가 commonmark-java로 렌더링·정화한 HTML을 쓴다(spec 6.4). 웹에는 마크다운 라이브러리를 넣지 않았다. `@tailwindcss/typography`의 `prose`로 스타일만 입힌다 |
| 아이콘 | lucide-react (shadcn 기본, 트리 셰이킹) |

PRD 7.1은 "구문 강조 없음"이라 적었지만, 팀장 지시(검증된 라이브러리로 코드 하이라이팅)에 따라 넣었다. 지연 로딩이라 목록·트리 화면 전송량에는 영향이 없다.

### 번들 크기

| 파일 | 원본 | gzip |
|---|---|---|
| `index-*.js` (React, Radix, 앱) | 432 KB | 135 KB |
| `common-*.js` (highlight.js, 파일 보기에서만) | 154 KB | 53 KB |
| `index-*.css` | 92 KB | 15 KB |

APK 안의 assets는 zip으로 압축되므로 APK 증가분은 약 200KB다. 가장 큰 덩어리는 react-dom(약 60KB gzip)이다. 더 줄여야 하면 Preact(`preact/compat`)로 바꿔 약 45KB를 줄일 수 있지만 Radix 호환성 검증이 필요해 이번에는 하지 않았다.

### CSP 지키는 방법

- `index.html`에는 외부 파일 `<script src>`, `<link>`만 있다. 테마 깜빡임 방지 스크립트도 `public/theme.js`로 뺐다.
- `style=""` 속성과 `<style>` 태그를 쓰지 않는다. React의 `style` prop과 Radix 위치 계산은 CSSOM(`el.style.x = ...`)이라 CSP 대상이 아니다.
- `react-remove-scroll`이 `<style>`을 주입하는 모달형 컴포넌트(Dialog, 모달 DropdownMenu/Select)는 쓰지 않는다. Popover는 비모달이다. 위에서 말한 대로 실기기 응답(CSP 헤더 포함)에서 콘솔 오류 0건을 확인했다.
- 외부 이미지는 `img-src 'self'`로 막히므로 README의 외부 이미지(배지 등)는 깨진 그림 대신 "[외부 이미지: alt]" 글자(링크)로 바꾼다.

## 3. 빌드 방법

```bash
cd web
npm ci            # 처음 한 번
npm run build     # tsc 타입 검사 + vite build → ../app/src/main/assets/web/ 를 비우고 다시 채운다
npm test          # node --test (줄 분할·언어 판별 단위 테스트)
cd .. && ./gradlew :app:assembleDebug
```

- Node 22 이상(개발: Node 26, npm 11). 결과물은 커밋한다. 웹 소스를 바꿨으면 `npm run build` 결과도 같이 커밋한다.
- 개발 서버: `adb forward tcp:8080 tcp:8080` 후 `npm run dev`. `/api`를 `http://localhost:8080`(또는 `MOBILEGIT_URL`)로 프록시한다. 단 raw 응답은 WR-2 때문에 개발 프록시에서 502가 난다(이미지 미리보기만 영향, 폰 직접 접속은 정상).
- shadcn 컴포넌트 추가: `cd web && npx shadcn@latest add <이름>`. 주의: shadcn CLI 4.22가 `import { cn } from "cn"`으로 잘못 써 넣는 버그가 있었다. 추가 후 `from "@/lib/utils"`로 고치고, 같이 설치되는 `cn` npm 패키지는 지운다.

## 4. 화면별 구현

주소 체계(해시): `#/` 목록, `#/r/<repo>` 홈, `#/r/<repo>/tree/<path>`, `#/r/<repo>/blob/<path>?L=<줄>`, `#/r/<repo>/commits/<path>?page=N`. 모든 화면에 `?ref=<브랜치|태그|SHA>`(기본 브랜치면 생략).

| 화면 | 요소 (PRD 7.2 대비) | 추가한 것 |
|---|---|---|
| 공통 | 상단 바(앱 이름, 테마 전환), 레포 화면에 레포 이름·브레드크럼·브랜치 선택(PRD 7.1) | 하단에 버전, "읽기 전용, 관리는 앱에서", 인증 꺼짐·익명 읽기 표시 |
| W-01 | 이름, 종류(아이콘+글자), 설명, 마지막 업데이트(미러)/push(로컬) 상대 시각(마우스를 올리면 절대 시각), 원본 상태 배지, LFS 누락 배지, 이름 필터 | 설명도 검색, 종류 필터(전체/미러/로컬/문제 N), 최근순/이름순, 원본 주소, 기본 브랜치, 용량, 행 전체 클릭, 레포가 없을 때 push 명령 예시 |
| W-02 | clone URL(접속한 호스트 기준 `location.origin`) + 복사, `git clone` 명령 복사, 브랜치/태그 선택(검색, 기본 표시, 보존 ref 제외), 최신 커밋(작성자, 메시지, 짧은 SHA, 시각), 루트 트리(폴더 먼저), README 렌더링, 미러면 원본 URL·"읽기 전용" 배지 | 원본 없음/인증 필요 배너, LFS·서브모듈 안내(F-24, URL 목록), 정보 카드(종류, 원본 상태, 마지막 업데이트/push, 기본 브랜치, 브랜치·태그 수, 용량, 보존 ref 수), 보존 ref 받기 명령(F-11 AC5), 분리 원본 표시, 모든 레포 화면 상단 Clone 팝오버 |
| W-02b | 하위 경로 트리, `..` 행, 하위 폴더 README | "기록" 버튼(이 경로의 커밋) |
| W-03 | 경로, 크기, 줄 번호, 1MB 초과·바이너리·LFS 포인터 안내(크기, OID), 원본 다운로드 | 구문 강조, 줄 번호 클릭 → `?L=` 강조·이동(번호는 `::before`라 복사에 섞이지 않음), 내용 복사, 이미지 파일 미리보기, README 안의 폴더 링크가 blob으로 오면 트리로 이동 |
| W-04 | 짧은 SHA, 메시지 첫 줄, 작성자, 시각, 50개씩 이전/다음, 경로별 이력 | 날짜별 묶음, 메시지 본문 펼치기, 전체 SHA 복사, "이 시점의 파일 보기"(ref=SHA로 트리) |
| W-E | 없는 레포/경로/브랜치 → 이유 + "레포 처음으로"/"레포 목록으로", 빈 레포 → "아직 커밋이 없어요" + `git remote add`/`git push` 명령 | 401(새로 고침 안내), 429(5분 차단), 네트워크 오류 문구 |

README 링크 처리(`lib/readme.ts`): 상대 링크는 파일 보기로, `/x`는 레포 루트 기준, 상대 이미지는 raw API로, `#앵커`는 해시 라우팅과 충돌하므로 링크를 뗀다. 외부 링크는 새 탭 + `noopener noreferrer`.

## 6. 자가 진단과 수정 내역

데스크톱 1280px(라이트·다크), 모바일 390px에서 15개 화면을 스크린샷으로 보고, 브랜치 전환·복사·README 링크·줄 강조·테마 전환·필터를 Playwright로 실행했다.

| # | 발견 | 수정 |
|---|---|---|
| D-1 | 모바일 레포 홈에서 경고·Clone·정보 카드가 파일 목록 위에 쌓여 첫 화면에 파일이 안 보임 | 파일·README를 먼저, 사이드바는 아래로. 모바일에서는 사이드바 Clone 카드를 숨기고 상단 Clone 버튼만 둠. 원본 없음/인증 필요는 전체 폭 배너로 위에 |
| D-2 | 데스크톱에서 LFS·서브모듈 안내가 Clone 카드보다 위 | Clone → 안내 → 정보 순서로 |
| D-3 | README 인라인 코드에 typography 기본 백틱이 그대로 보임 | 백틱 제거, 회색 바탕으로 |
| D-4 | 커밋 페이지 첫 페이지의 비활성 "이전" 버튼에서 아이콘과 글자가 위아래로 갈라짐 | 비활성일 때 `asChild` 없이 버튼 자체에 내용 |
| D-5 | 모바일 커밋 행에서 SHA·버튼이 한 줄을 따로 차지 | 한 줄 배치, 모바일은 SHA 글자를 숨기고 복사·보기 아이콘만 |
| D-6 | 날짜 묶음 제목이 "10월 25일 일"로 요일이 어색 | "일요일"로 |
| D-7 | README의 외부 배지 이미지가 CSP에 막혀 깨진 아이콘으로 보일 것 | "[외부 이미지: alt]" 글자로 바꾸고, 이미 링크 안이면 중첩 링크를 만들지 않게 span으로 |

판단:
- **사용자 친화적인가**: 문구는 앱과 같은 해요체. 모든 빈 상태와 오류가 원인 + 다음 행동(명령 예시, 돌아갈 링크)을 준다. 복사는 http(보안 컨텍스트 아님)에서도 되도록 `execCommand` 대체가 있다. 링크가 평범한 `<a>`라 새 탭·뒤로 가기·주소 공유가 된다.
- **한눈에 보이는가**: 목록에서 종류·원본 상태·LFS·마지막 활동이 한 행에 보인다. 레포 홈 첫 화면(1280×900)에 Clone 주소, 브랜치 선택, 최신 커밋, 파일 목록, 원본 상태, 경고가 스크롤 없이 보이고 README는 바로 아래다. 코드/커밋 탭이 모든 레포 화면 상단에 있다.
- **현대적이고 깔끔한가**: shadcn 기본 컴포넌트, 회색 바탕 + 흰 카드, 강조색은 Clone 버튼과 링크에만. 다크 모드에서 구문 강조 색도 바뀐다.

## 7. 남은 문제

| 항목 | 내용 |
|---|---|
| 해시 주소 | WR-1이 반영되면 history 라우팅으로 바꿀 수 있다 (`lib/router.ts`만 수정) |
| 개발 프록시에서 raw 502 | WR-2. 폰 직접 접속에는 영향 없음 |
| 캐시·압축 | WR-3, WR-4. 지금은 매 방문마다 약 680KB를 받는다 (LAN에서는 체감 없음, 핫스팟 데이터에는 불리) |
| 확인하지 못한 브라우저 | Chromium(Playwright)만 확인. Firefox·Safari 미확인 |
| `.md` 파일 보기 | README가 아닌 Markdown 파일은 원문(강조 포함)으로 보인다. 렌더링 API가 디렉터리 README에만 있어서다. 필요하면 코어에 `/render?path=` 요청 |
| 서브모듈 항목 | 트리에서 이름과 "서브모듈" 표시만, 원본 링크는 없음(트리 API가 URL을 주지 않음. 레포 홈 안내에 URL 목록은 있음) |
