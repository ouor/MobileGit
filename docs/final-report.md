## 2차에서 바뀐 것
- 실패·원본 사고가 보임: 목록 이유와 기간, 오류(빨강)/주의(주황) 요약, "주의 필요" 필터, 히스토리 바뀜 배지.
- 보존된 기록 화면(앱 A-15, 웹 W-05)과 업데이트 이력의 변경 종류.
- ngrok: 기본 꺼짐, 재시작·업데이트 뒤 자동으로 켜지지 않음. "비밀번호 없이 공개"는 경고 후 사용자가 고를 수 있음(사용자 결정). 루프백 포트 익명 읽기 차단.
- 실패 판정을 JGit 고정 메시지 기반으로 재작성(공용 와이파이 로그인 페이지 오판 등 수정).
- 용어집 확정과 앱·웹 문구 통일, 접근성(대비, 48dp, 큰 글꼴), LFS 미지원 명시, 추가 시트 3개로 정리, 뒤로 가기 단계 이동.
- 루트 README 작성.

## 확인하지 못한 것
- 실제 ngrok 토큰으로의 외부 접속과 익명 clone(가짜 토큰으로 실패 경로만 확인).
- USB 테더링, 알림 권한 끔, 시스템 글꼴 200%, Android 12 이하 줄바꿈, 360dp 폭.
- 재부팅 경로(앱 업데이트 직후 ngrok 꺼짐은 강제 종료로만 확인).
- 알림 창의 로봇 아이콘(RV2-11): 테스트폰의 아이콘 캐시로 추정, 재부팅으로 미확인.

- 웹 "PR 브랜치 바뀜"은 실데이터로 나올 일이 없음(PR 브랜치는 보존하지 않음). 앱 이력에는 나옴.
