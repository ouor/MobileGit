## 공통 요구 (3명 이상)
- **아카이브 보존**: 원본이 force-push하거나 레포를 삭제·비공개 전환해도 내 쪽 히스토리와 refs가 남아야 함 (01, 02, 03, 05)
- **동기화 상태와 실패 알림**: 마지막 동기화 시각, 성공/실패, 원본 404·비공개 전환 감지. "미러가 몇 달째 멈춘 걸 늦게 알았다"는 경험이 반복됨 (01, 02, 05, 03)
- **백그라운드 신뢰성**: Doze와 제조사(삼성) 배터리 최적화가 서버를 죽이는 문제가 가장 큰 불안 요소. 화면이 꺼져도 유지되어야 하고, 제조사별 안내가 필요함 (01, 03, 04, 05)
- **기본이 닫힌 보안**: ngrok은 기본 꺼짐으로 명시적으로 켰을 때만, 인증 필수, 토큰은 Keystore에 암호화 저장, 접속 로그 (01, 03, 05, 02)
- **표준 git만으로 clone/push** (전용 클라이언트 불필요) (01, 05, 04)
- **공유 시트에서 바로 미러 등록** (01, 02)
- **폰 밖으로 꺼내기**: bundle, manifest 내보내기. 폰이 유일한 사본이 되면 안 됨 (01, 02, 05)

## 개별 요구
- 와이파이에서만 갱신, 원본 대비 앞/뒤 커밋 수 표시, 셀프호스팅 GitLab과 Bitbucket PAT 지원 (03)
- 노트북에서 push 못한 커밋을 폰 핫스팟으로 push해 "일단 안전"하게 두는 보험 (03)
- 수업용: 30명 동시 clone, QR 주소, 읽기는 인증 없이 하고 쓰기만 인증하는 옵션, 누가 언제 push했는지 보기, 접속 진단(AP 격리 등) (04)
- 앱을 지우면 데이터도 사라지는지 분명히 알림, LFS 미지원 경고, 큰 레포에서 JGit 메모리 우려 (05)
- 히스토리 전체를 받을 것 (shallow 금지) (02)

## 사용자 결정과 다른 의견 (PM 판단 시 참고)
- ngrok, 웹 화면은 "없어도 된다"는 의견이 많았음 → 사용자가 확정한 기능이므로 유지하되, ngrok은 기본 꺼짐으로, 웹 화면은 읽기 전용으로 단순하게
- 강사(04)는 미러에 수업 중 수정분을 push하길 원함 → 미러는 읽기 전용(사용자 결정). 이 경우는 "미러를 로컬 레포로 분리(fork)" 기능으로 해결 가능
