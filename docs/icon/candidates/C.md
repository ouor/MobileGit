# 시안 C1 / C2

공통: 검은 스퀘어클(4개 큐빅 세그먼트로 만든 초타원, n≈4) 위에 하얀 원(r=336, 지름 672 = 캔버스의 65.6%로 66% 안전 영역 안). 브랜치 그래프는 원 안쪽, 중심에서 최대 302px 이내에 있어 안전 영역(반경 338) 안에 여유 있게 들어갑니다. 공식 Git 로고의 마름모와 대각선 구도는 쓰지 않았습니다.

## C1 — Merge Loop (`C1.svg`)
- 콘셉트: 갈라졌다가 다시 합쳐지는 브랜치로, 원격(GitHub)과 폰 미러가 동기화되는 순환을 표현합니다.
- 브랜치 해석: 세로 줄기 하나에 노드 2개(위·아래)가 있고, 위쪽에서 오른쪽 레인으로 갈라져 나간 브랜치가 레인 가운데 노드를 지나 다시 줄기로 **병합**됩니다. 노드는 3개입니다. 꺾이는 곳은 둥근 Q 곡선이고 선 끝은 round cap입니다. 선 굵기 54, 노드 반지름 66입니다.
- 광학 보정: 줄기가 무거워서 줄기는 x=408, 레인 노드는 x=624에 두었습니다. 기하 중심은 515로, 오른쪽으로 3px 치우쳐 시각적 무게를 맞췄습니다.

## C2 — Angular Fork (`C2.svg`)
- 콘셉트: 하나의 뿌리에서 갈라져 나온 미러로, 원본에서 분기해 폰에 보관한 사본을 뜻합니다.
- 브랜치 해석: 아래 루트 노드에서 위로 줄기가 올라가고, 루트 바로 위에서 45° 대각선으로 갈라진 브랜치가 꺾여 수직으로 올라갑니다. **병합하지 않는** 갈래형이고 노드는 3개이며, 브랜치 끝은 줄기 끝보다 낮게 두어 비대칭을 만들었습니다. 선 굵기 64(C1보다 굵음), 모서리는 miter(직각·45° 각진 처리)이고 선 끝은 butt cap, 노드 반지름은 70입니다.
- 광학 보정: 좌우 바깥 끝(362~662)의 중심이 512에 오도록 배치했습니다.
