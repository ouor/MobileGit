# 시안 A (mobilegit 앱 아이콘)

공통: 1024 캔버스, 검은 스퀘어클(4개 대칭 큐빅 베지어, 손으로 쓴 path), 가운데 하얀 원 r=320(지름 62.5%), 브랜치는 검정 단색.
안전 영역: 66% 원(반지름 338) 기준. 하얀 원(320)과 브랜치 전체(중심에서 최대 247 / 286)가 모두 안에 들어감.
렌더링: Playwright Chromium으로 512px, 48px PNG 출력 후 직접 확인.

## A1: 곡선 포크 (세로)

- 콘셉트: "원본에서 갈라져 나온 미러". 줄기에서 부드럽게 휘어 나가 위로 서는 가지 하나로, 원격 레포를 폰에 받아 둔 모습을 표현.
- 브랜치 해석: 세로 메인 라인 + 오른쪽으로 갈라지는 가지 1개, 노드 3개(뿌리 1, 머리 2), 병합 없음. S자 베지어 곡선, 둥근 끝(round cap).
- 수치: 선 64, 노드 지름 120. 48px에서 각각 약 3.0px, 5.6px.
- 가독성: 512px에서는 형태가 깔끔함. 48px에서도 노드 3개와 Y자 갈래가 또렷하게 구분됨. 노드 사이 흰 틈은 48px에서 약 3px.

## A2: 각진 포크 (가로)

- 콘셉트: "타임라인 위로 올라서는 브랜치". 왼쪽에서 오른쪽으로 흐르는 커밋 시간축에서 45도로 갈라져 나란히 달리는 두 레인.
- 브랜치 해석: 가로 메인 라인 + 위로 45도 꺾이는 가지 1개, 노드 3개(시작 1, 끝 2). 직선과 마이터 모서리, 잘린 끝(butt cap). 곡선을 쓰는 A1과 방향·모서리 처리가 다름.
- 수치: 선 56, 노드 지름 120, 두 레인 간격 176. 48px에서 각각 약 2.6px, 5.6px, 8px.
- 가독성: 48px에서 평행한 두 레인, 대각선, 오른쪽 끝의 노드 2개가 분리되어 보임. 다만 USB 기호와 실루엣이 조금 닮은 점은 주의 필요.

## 검토 후 버린 안
- 세로 곡선 병합(가지가 나갔다가 다시 합류): 간격이 좁아 "재생 버튼" 삼각형처럼 보여서 제외.
- 가로 병합(사다리꼴, 위쪽 노드 1~2개): 48px에서 삼각형/분자 기호나 모자처럼 읽혀서 제외.
- 직각 브리지(ㄷ자 우회): 서류가방처럼 보여서 제외.

## A1 색 조합 3안 (A1 채택 후)

형태는 A1 그대로이고 색만 바꿨습니다. 원은 모두 흰색 `#FFFFFF`입니다. 비교 이미지는 `A1-colors-sheet.png`이며, 앱 화면 바탕인 밝은 `#F2F4F6`과 어두운 `#111215` 위에 160px, 48px로 놓았습니다.

| 안 | 배경 | 브랜치 | 브랜치:원 대비 | 배경:밝은 바탕 / 어두운 바탕 |
|---|---|---|---|---|
| color1 | `#3366FF` | `#3366FF` | 4.7:1 | 4.2:1 / 4.0:1 |
| color2 | `#00A86B` | `#007A4D` | 5.4:1 | 2.8:1 / 6.1:1 |
| color3 | 그라데이션 `#22C3FF` → `#3355FF` (왼쪽 위 → 오른쪽 아래) | `#1B3FCC` | 8.0:1 | 1.8:1~ / 3.5:1~ |

- **color1, 브랜드 파랑 단색**: 앱 강조색 `#3366FF` 하나로 배경과 브랜치를 같이 칠했습니다. 앱 화면과 가장 일관되고, 토스식으로 "색 하나"를 지킵니다. 양쪽 바탕 모두에서 대비가 4:1 이상으로 가장 고르게 눈에 띕니다.
- **color2, 민트 그린**: 디자인 시스템의 tertiary `#00A86B`와 success 글자색 `#007A4D`를 썼습니다. "안전한 보관함" 느낌을 주고 홈 화면의 파랑 앱들 사이에서 구별됩니다. 어두운 바탕에서 특히 강하고, 밝은 바탕에서는 2.8:1로 셋 중 약한 편이지만 채도가 높아 눈에는 잘 띕니다.
- **color3, 하늘색에서 파랑으로 흐르는 그라데이션**: 브랜드 파랑을 유지하면서 깊이와 활기를 더한 안입니다. 브랜치를 진한 파랑 `#1B3FCC`로 둬서 48px에서 원 대비가 가장 높습니다(8.0:1). 왼쪽 위 밝은 하늘색은 밝은 바탕에서 경계가 약해지지만 오른쪽 아래 파랑이 실루엣을 잡아 줍니다.

다른 개발자 도구와 겹치지 않는지:
- Git 공식 로고는 주황빨강 `#F05032`, GitLab은 주황 `#FC6D26`, GitHub는 검정/흰색입니다. 세 안 모두 이 색들을 피했습니다.
- Bitbucket은 진파랑 `#0052CC`이지만 형태(양동이)가 달라서 color1, color3과 헷갈릴 가능성은 낮다고 봅니다.
- Gitea(`#609926`, 올리브 그린)와 Android Studio(`#3DDC84`, 연두)는 초록 계열이지만, color2는 청록 쪽 민트라 색상이 구분됩니다.

48px 확인: 세 안 모두 흰 원 안에서 노드 3개와 갈래가 분명하게 보입니다. 브랜치:원 대비는 모두 4.5:1 이상입니다.
