# 시안 A (mobilegit 앱 아이콘)

공통: 1024 캔버스, 검은 스퀘어클(4개 대칭 큐빅 베지어, 손으로 쓴 path), 가운데 하얀 원 r=320(지름 62.5%), 브랜치는 검정 단색.
안전 영역: 66% 원(반지름 338) 기준. 하얀 원(320)과 브랜치 전체(중심에서 최대 247 / 286)가 모두 안에 들어감.
렌더링: Playwright Chromium으로 512px, 48px PNG 출력 후 직접 확인.

## A1: 곡선 포크 (세로)

- 콘셉트: "원본에서 갈라져 나온 미러". 줄기에서 부드럽게 휘어 나가 위로 서는 가지 하나로, 원격 레포를 폰에 받아 둔 모습을 표현.
- 브랜치 해석: 세로 메인 라인 + 오른쪽으로 갈라지는 가지 1개, 노드 3개(뿌리 1, 머리 2), 병합 없음. S자 베지어 곡선, 둥근 끝(round cap).
- 수치: 선 64, 노드 지름 120. 48px에서 각각 약 3.0px, 5.6px.
- 가독성: 512px에서는 형태가 깔끔함. 48px에서도 노드 3개와 Y자 갈래가 또렷하게 구분됨. 노드 사이 흰 틈은 48px에서 약 3px.

## A2: 각진 포크 (가로)

- 콘셉트: "타임라인 위로 올라서는 브랜치". 왼쪽에서 오른쪽으로 흐르는 커밋 시간축에서 45도로 갈라져 나란히 달리는 두 레인.
- 브랜치 해석: 가로 메인 라인 + 위로 45도 꺾이는 가지 1개, 노드 3개(시작 1, 끝 2). 직선과 마이터 모서리, 잘린 끝(butt cap). 곡선을 쓰는 A1과 방향·모서리 처리가 다름.
- 수치: 선 56, 노드 지름 120, 두 레인 간격 176. 48px에서 각각 약 2.6px, 5.6px, 8px.
- 가독성: 48px에서 평행한 두 레인, 대각선, 오른쪽 끝의 노드 2개가 분리되어 보임. 다만 USB 기호와 실루엣이 조금 닮은 점은 주의 필요.

## 검토 후 버린 안
- 세로 곡선 병합(가지가 나갔다가 다시 합류): 간격이 좁아 "재생 버튼" 삼각형처럼 보여서 제외.
- 가로 병합(사다리꼴, 위쪽 노드 1~2개): 48px에서 삼각형/분자 기호나 모자처럼 읽혀서 제외.
- 직각 브리지(ㄷ자 우회): 서류가방처럼 보여서 제외.
