## 여러 리뷰어가 함께 지적한 것 (최우선)
- **ngrok 루프백 포트의 익명 읽기**: R2SEC-01, R2GIT-09, R2ARC-07. ngrok이 꺼져 있어도 폰 안의 다른 앱이 "push할 때만" 설정에서 비밀번호 없이 clone 가능. 익명 허용을 "ngrok 켜짐 + 터널 연결됨"으로 좁히고 `anonymousOk` 기본값을 false로.
- **"안 봄"과 "마지막 보존 시각" 필드 겸용**: R2AND-03, R2ARC-01, R2GIT-08. 필드를 나누고, 본 것 표시는 본 시점 이전 보존만 지우게.
- **저장 폴더 이름 해석 두 벌 + 메인 스레드 질의**: R2AND-04, R2ARC-05.
- **실패 분류와 상태 전이**: R2GIT-01(본문 텍스트로 판정), R2GIT-02(확인 성공이 업데이트 실패를 지움), R2GIT-03(네트워크 오류가 원본 없음을 덮음), R2GIT-04(멈춤 판정). QA2-01 수정이 다른 쪽으로 넘쳤음. 1차 QA·2차 QA 시나리오를 회귀 테스트로.
