## 여러 리뷰어가 함께 지적한 것 (최우선)
- **저장 파일 읽기 실패 → 초기화 후 덮어쓰기**: ARC-01, ARC-02, AND-03, GIT-15. 설정·비밀번호·토큰·미러 원본 URL 유실. 스키마 버전과 관대한 디코딩 필요
- **큰 레포 첫 받기가 끝나지 않음**: AND-04, GIT-08 (WorkManager 10분 제한, 취소가 실패로 기록, 이어 받기 없음, 받는 중 공간 하한 미확인)
- **남는 파일과 정리 부재**: GIT-01(ref .lock), GIT-05(삭제 중 크래시), ARC-04(고아 디렉터리·임시 파일), AND-12·ARC-07(내보내기 캐시)
- **커밋 API 상한 없음**: GIT-09, SEC-11

## 담당 배분
처리 원칙: 치명·높음·중간은 모두 고칩니다. 낮음은 작으면 고치고, 아니면 이유와 함께 "나중"으로 기록합니다. 아키텍트가 "나중"으로 분류한 항목(ARC-06, 08, 09, 10, 11, 12, 14, 16, 17)은 2차 사이클 이후로 미뤄도 됩니다. 단, ARC-13(문자열 키)은 2차 UI 작업 전에 처리합니다.

- git 서버: GIT-01~16 전부
- 보안: SEC-01~12 전부 (SEC-05의 "인텐트로 들어온 URL은 사용자 확인 후 probe" 중 화면 쪽은 안드로이드 UI와 협의)
- 아키텍처: ARC-01~05, ARC-07, ARC-15, ARC-18
- 기기 확인이 필요한 항목: AND-02(중복 기동 재현), SEC-01(ngrok 헤더 동작), SEC-04(IPv6 바인딩, `adb shell ss -ltn`)
