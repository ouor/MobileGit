## 관찰 (문제로 올리지 않음)

- PC 프로젝트 올리기 안내를 위로 끌어 펼친 상태에서 뒤로 가기를 누르면, 네 갈래 목록으로 돌아가지 않고 시트만 접힌다. 한 번 더 누르면 시트가 닫힌다. 다른 갈래를 고르려면 시트를 닫고 "레포 추가"를 다시 눌러야 한다. 안드로이드 UI 담당이 의도한 동작인지 확인 필요(낮음 수준).
- 서버 스위치의 접근성 이름은 켜진 상태에서도 "서버 켜기"다. 스위치의 켜짐 상태가 함께 읽히므로 문제로 보지 않았다. 메인 "레포 추가" 버튼이 uiautomator 덤프에 나오지 않는 점은 1차와 같다(TalkBack 미확인).
