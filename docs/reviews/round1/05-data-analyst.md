# mobilegit 1차 리뷰: 29살 스타트업 데이터 분석가

## 1. 첫인상: 토스나 당근처럼 깔끔하고 현대적인가?

**대체로 그렇습니다.** 회색 바탕에 흰 둥근 카드를 올리고, 파란색 하나를 포인트로 쓰고, "~해요" 말투를 쓰는 점이 토스와 거의 같은 문법이에요. 그래서 처음 보는 앱인데도 낯설지 않았어요.

**좋은 점**
- `08-storage.png`(저장 공간)가 제일 토스 같아요. 큰 숫자(4.1 MB) 아래에 막대 그래프를 두고, 레포별 용량을 큰 순서로 보여 줘서 한눈에 들어와요.
- `01-main.png` 맨 위 "서버 켜짐" 카드는 초록 점, 큰 토글, 큰 주소 글씨가 있어서 지금 상태가 바로 보여요.
- PC 웹(`09`~`12`)은 GitHub와 거의 같은 구조라서 따로 배울 필요가 없었어요. README 렌더링, 코드 하이라이트, 날짜별 커밋 묶음도 다 깔끔해요.
- 다크 모드(`13`, `14`)도 색이 무너지지 않고 잘 나와요.

**어색한 점**
- 화면을 열면 가장 큰 자리를 "서버"가 차지해요. 저 같은 사용자에게 이 앱의 주인공은 "내 레포들"인데, 레포 목록은 화면 절반 아래에서 시작해요. 토스 홈은 내 돈(계좌)이 먼저 나오고 설정 같은 건 뒤로 빠져 있잖아요.
- 화면 곳곳에 개발자 용어가 그대로 나와요(ref, PR ref, HEAD, 원격 자격 증명, bundle, 하한). 디자인은 토스인데 문구는 터미널이라 그 차이가 꽤 크게 느껴져요.
- 앱은 "레포", 웹은 "레포지토리"로 같은 걸 다르게 불러요. 미러 아이콘도 앱은 ⇄, 웹은 ↻(새로고침 모양)이라 서로 달라요.

## 2. 무엇을 할 수 있는 앱인지 한눈에 보이나?

**반쯤 보입니다.** "폰에 git 서버가 돌고 있고, 레포가 15개 있다"는 건 바로 알겠어요. 하지만 "그래서 내가 PC에서 뭘 하면 되지?"는 화면만 봐서는 안 보여요.

헷갈렸거나 찾기 어려웠던 것:
- **미러와 로컬의 차이.** 필터 칩에 "미러 12 / 로컬 3"이 있는데 무슨 뜻인지는 어디에도 설명이 없어요. `04`의 "읽기 전용 미러"와 `05`의 "로컬 레포 · push 가능"까지 들어가 봐야 감이 와요.
- **로컬 레포는 어떻게 만드나?** `01`의 버튼은 "레포 추가"인데, 누르면 나오는 `02` 화면 제목은 "미러 추가"예요. 그럼 로컬 레포는요? `05`를 보니 "PC에서 push"로 생긴 것 같은데, 이걸 알려 주는 곳이 없어요. 저는 이 앱의 가장 중요한 기능이 "PC에서 이 폰으로 push하기"라고 생각하는데, 그 방법이 가장 꼭꼭 숨어 있어요.
- **주소 안내 문구** `<주소>/<레포>.git`(`01`)는 개발자에게는 익숙한 표기지만, 저는 "꺾쇠를 그대로 치라는 건가?" 하고 잠깐 멈칫했어요.
- **배터리 칩**(`01`): "배터리 최적화 해제 필요"는 눌러도 되는 건지, 왜 필요한지, X를 누르면 문제가 생기는지 알 수 없어요.
- **계정·조직 일괄 미러**(`03`)는 아주 좋은 기능인데, 들어가는 입구가 어디인지 스크린샷만으로는 못 찾았어요(아마 ⋮ 메뉴 안에 있는 것 같아요).
- 노트북을 주로 올리는 저로서는 **웹에서 .ipynb가 렌더링되는지**가 가장 궁금했는데, 이 부분은 확인할 수 없었어요.

## 4. 바꿨으면 하는 점 (우선순위 순)

1. **"PC에서 이 폰으로 올리기"를 첫 화면에 보이게 해 주세요.** 레포가 0개일 때와 "레포 추가" 시트에 "GitHub에서 가져오기(미러)" / "PC에서 새로 올리기(로컬)" 두 선택지를 두고, 로컬을 고르면 `git remote add phone http://…/이름.git` 명령과 "VS Code에서는 이렇게 하세요" 안내를 복사 버튼과 함께 보여 주세요.
2. **메인 화면 위계를 바꿔 주세요.** 서버 카드는 한 줄짜리 상태 바(● 켜짐 · 192.168.31.120:8080 · 복사)로 줄이고, 레포 목록을 위로 올려 주세요. 자세한 서버 정보는 상태 바를 누르면 펼쳐지게 하면 돼요.
3. **용어를 사람 말로 바꿔 주세요.** ref → 브랜치·태그, 원격 자격 증명 → 로그인 정보, 하한 → 최소 남은 공간, 측정 → (삭제), 앱과 웹 모두 "레포"로 통일. 미러/로컬은 처음 한 번 짧은 설명을 띄워 주세요("미러: GitHub 원본을 자동으로 따라가는 사본, 수정 불가").
4. **이중 부정 토글을 없애 주세요.** "인증 끄기" → "비밀번호 요구", "자동 업데이트에서 제외" → "자동 업데이트".
5. **PR ref 같은 고급 옵션은 접어 두세요.** `02`, `04`에서 "고급 설정" 아래로 옮기면 화면이 절반으로 줄어요.
6. **미러 상세(`04`)에도 clone 주소 카드를 로컬(`05`)과 같은 위치에 넣어 주세요.** "지금 업데이트 / 변경 확인만"은 버튼 하나로 합치거나 차이를 한 줄로 설명해 주세요.
7. **FAB이 목록 글자를 가리지 않게** 목록 아래쪽에 여백을 주세요(`01`, `13`).
