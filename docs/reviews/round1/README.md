## 공통 개선 요구 (우선순위 순, 괄호는 언급한 리뷰어)

### 안드로이드 앱
1. **로컬 레포 만드는 법이 안 보임** (5명 전원): "레포 추가" 버튼이 "미러 추가" 화면만 엽니다. PC에서 push해 새 레포를 만드는 방법(`git remote add` + `git push` 명령과 계정 정보)과 빈 레포 만들기가 보이지 않습니다. 일괄 미러로 가는 입구도 메인에 없습니다. → "레포 추가"를 바텀시트로 바꿔 미러 추가 / 계정·조직 일괄 미러 / PC에서 새 레포 올리기(명령 복사) / 빈 레포 만들기를 모으자는 제안 (01, 02, 03, 04, 05)
2. **메인 서버 카드가 화면의 40~45%를 차지** → 레포가 2개 반만 보임. 한 줄 요약(스위치 + 주소 + 상태)으로 접고 자세한 건 펼치기/탭으로 (02, 03, 05, 01)
3. **개발자 용어** (ref, PR ref, HEAD, 원격 자격 증명, 하한, 측정, WireGuard 등) → 쉬운 말로 바꾸고 전문 옵션은 "고급"으로 접기. 레포/레포지토리/저장소 용어와 미러 아이콘(앱 ⇄, 웹 ↻) 통일 (01, 03, 04, 05)
4. **이중 부정 토글**: "인증 끄기", "자동 업데이트에서 제외" → 긍정형("인증 사용", "자동 업데이트")으로. 인증을 끌 때 확인 창 (02, 03, 04, 05, 01)
5. **"레포 추가" 버튼이 목록 마지막 항목의 용량 글자를 가림** (01, 13 특히 다크) → 목록 하단 여백 (01, 02, 03, 04, 05)
6. **주소가 단어 중간에서 줄바꿈** (`field` / `-notes.git`, 04·05·06) → 손으로 옮길 때 실수. `/`나 `:` 같은 경계에서만 끊기 (02, 03, 04, 05)
7. **미러 상세(04)에 clone 주소가 없고 04와 05 구조가 다름** → 같은 구조로 통일, 둘 다 clone 주소를 첫 화면에 (01, 02, 05)
8. **레포 삭제 버튼이 내보내기 바로 아래 같은 카드에** (05) → 위험 영역으로 분리 (01, 02)
9. **"원본 정상" 같은 정상 상태 배지 남발** → 문제가 있을 때만 사유 표시 (02, 03, 05)
10. **QR 화면(06)에 복사·공유 버튼 없음** (03, 04)
11. **중요 안내가 작은 회색 글씨**(01 안내문, 07 평문 HTTP 경고) → 평문 HTTP 경고는 메인으로, 핵심 안내는 대비 높이기 (04)
12. **선택 상태가 불분명**: 03의 이미 등록된 항목이 회색 체크박스, 칩 선택 표시 (03, 04)
13. **다크 모드 대비**: FAB(13) (02)
