# mobilegit 1차 리뷰: 프로덕트 디자이너 (31세)

> 핀테크 회사 프로덕트 디자이너. 토스, 당근, 무신사, 배민, 리디를 자주 씀. git은 GitHub Desktop으로 포트폴리오(GitHub Pages)를 올릴 때만 써 봄. 정보 위계, 여백, 문구를 많이 보는 편.

---

## 1. 첫인상: 토스나 당근처럼 깔끔하고 현대적인가?

**절반쯤은 그렇습니다.** 개발자 도구치고는 꽤 공들인 티가 나요.

**좋은 점**
- 둥근 흰 카드를 연회색 배경 위에 얹고, 포인트 색은 파란색 하나만 쓰고, 문장은 "~해요"체로 맞췄어요. 토스 문법을 잘 따라 했습니다. 특히 `08-storage.png`는 토스 "자산" 탭과 비슷할 만큼 정돈돼 있어요. 큰 숫자 하나(4.1 MB)를 먼저 보여 주고 그 아래 막대로 나눠 보여 주는 위계가 좋았어요.
- `02-add-mirror.png`에서 주소를 붙여넣으면 바로 "접근 가능" 초록 카드가 뜨고, `/tree/main`까지 붙은 주소를 `.git` 주소로 알아서 고쳐 줘요. 이렇게 사용자 실수를 조용히 받아 주는 점은 토스다웠어요.
- `03-bulk-mirror.png` 하단의 "선택 111 KB · 남은 공간 97.6 GB"와 "2개 등록" CTA 조합이 좋아요. 버튼 문구에 개수를 넣은 것은 배민 장바구니 버튼 같아서 편했어요.
- 웹(`10`, `11`, `12`)은 GitHub와 거의 같아서 처음 봐도 어디를 눌러야 할지 바로 보였어요.

**어색한 점**
- **문구가 반쯤은 토스, 반쯤은 터미널이에요.** 말투는 친절한데 단어가 "ref", "PR ref", "원격 자격 증명", "HEAD", "하한", "fork/archived 제외", "clone 주소"예요. 토스는 "이체"를 "송금"이라고 쓸 만큼 쉬운 말에 집착하는데, 이 앱은 말투만 부드럽고 어휘는 그대로 개발자 용어예요.
- **메인(`01-main.png`) 첫 화면의 40%를 서버 카드가 차지해요.** 정작 제 레포 목록은 화면 아래쪽에 3개 반만 보여요. 당근으로 치면 홈 첫 화면 절반이 "위치 인증 상태" 카드인 셈이에요.
- 같은 뜻을 가리키는 말이 섞여 있어요: 레포 / 레포지토리 / 저장소, 업데이트 / 동기화 / 미러. 미러를 뜻하는 아이콘도 앱에서는 ⇄, 웹에서는 ↻로 서로 달라요.

## 2. 무엇을 하는 앱인지 한눈에 알 수 있나?

**아니요. 화면만 봐서는 30% 정도만 이해돼요.**

- 메인에서 알 수 있는 건 "폰이 서버로 켜져 있고, 주소는 192.168…"이라는 사실뿐이에요. 왜 서버가 필요하고 나한테 어떤 이득이 있는지는 어디에도 쓰여 있지 않아요. 웹 헤더에 붙은 "폰 속 git 서버 · 읽기 전용"(`09`)이 오히려 가장 잘 설명하는 한 줄이었어요. 정작 앱에는 이런 한 줄 소개가 없어요.
- **"미러"와 "로컬"의 차이를 이해하지 못했어요.** 필터 칩(`01`)에 "미러 12 / 로컬 3"이 있는데, 상세 화면까지 들어가서 "읽기 전용 미러"(`04`), "로컬 레포 · push 가능"(`05`)이라는 문구를 보고 나서야 감이 왔어요. 목록에서 미러는 ⇄ 아이콘에 하늘색 배경이고 로컬은 폴더 아이콘인데, 아이콘만 보고는 의미를 알 수 없어요.
- **로컬 레포를 만드는 방법을 찾지 못했어요.** "레포 추가" FAB(`01`)를 누르면 "미러 추가"(`02`)가 나와요. 로컬 레포는 `05`의 "만든 방법: PC에서 push"를 보고 나서야 PC에서 push하면 생긴다는 걸 추측했어요. FAB 라벨은 "레포 추가"인데 실제로는 미러만 추가할 수 있어서 기대와 결과가 어긋나요.
- 여러 레포를 한꺼번에 미러하는 화면(`03`)은 어디로 들어가는지 스크린샷만으로는 보이지 않아요. 메인 우상단 ⋮ 메뉴 안에 있다면 너무 깊이 숨어 있는 거예요.
- 웹 우상단의 모니터 아이콘(`09`~`12`)은 무엇을 하는지 모르겠어요. 테마 전환 같은데 라벨도 툴팁도 없어요.
- `04`의 "수정하려면 로컬 레포로 분리하세요"에서 "분리"가 어디에 있는 기능인지 화면에 버튼이 보이지 않아요. ⋮ 메뉴 안에 있다면 안내 문구 바로 옆에 링크를 달아 주세요.

## 3. 화면별로 눈에 걸리는 점

### 01-main.png (메인, 라이트)
- 서버 카드 안에 상태, 주소, 설명 2줄, Tailscale 링크까지 들어 있어 정보가 너무 많아요. 매일 볼 필요는 없는 정보예요.
- 설명 문구 "git으로는 <주\n소>/<레포>.git"이 `<주소>` 단어 중간에서 줄바꿈돼요. 꺾쇠 괄호 표기는 일반 사용자에게 문법처럼 보여요.
- "배터리 최적화 해제 필요" 칩은 X 버튼이 붙어 있어 무시해도 되는 태그처럼 보여요. 실제로는 꼭 해야 하는 일인데, 눌러서 설정으로 갈 수 있는지도 보이지 않아요. 노란 칩보다는 "해제하기" 버튼이 달린 배너가 맞아요.
- "레포 15"의 숫자만 파란색인데, 링크처럼 보여요. 강조할 이유가 없어요.
- "문제 있음 0" 칩은 0인데도 칩 4개 중 가장 넓은 자리를 차지해요. 문제가 있을 때만 보여 주고 빨간 점을 붙이는 편이 나아요.
- 레포 카드 중 git-consortium(미러)에만 ⋮ 버튼이 있고 로컬 카드에는 없어요. 규칙이 있는 건지 버그인지 알 수 없어요.
- FAB가 field-notes 카드의 용량 텍스트를 가려요(`13`에서는 "5.9 KB"가 "5.9 KE"로 잘려 보여요). 목록 아래쪽에 FAB 높이만큼 여백이 필요해요.

### 02-add-mirror.png (미러 추가)
- 제목이 "미러 추가"인데, 처음 쓰는 사람은 "미러"가 무슨 뜻인지 몰라요. "GitHub 레포 가져오기" 정도면 바로 이해돼요.
- 입력 라벨 "(여러 줄 가능)"은 여러 개를 한 번에 넣을 수 있다는 뜻인 듯한데, "한 줄에 하나씩, 여러 개도 돼요"처럼 의도를 풀어 써 주세요.
- "주소: <폰 주소>/strip-ansi.git" 도움말이 다음 필드의 라벨 "원격 자격 증명"과 거의 붙어 있어요. 이 부분만 여백이 4px 정도로 보여요.
- "원격 자격 증명"은 "GitHub 로그인 정보" 정도로 바꿔 주세요. 기본값 "없음 (공개 레포)"는 친절해서 좋아요.
- "ref 26개 받기 · PR ref 34개 제외 · 기본 브랜치 main"은 저에게는 암호예요. "브랜치·태그 26개를 받아요" 정도면 충분하고, PR ref 이야기는 고급 옵션으로 접어 두세요.
- "PR ref도 받기" 토글은 설명문에 "보존 대상이 아니고"라는 말이 들어가 있어요. 굳이 켤 필요가 없다는 뜻이라면 기본 화면에서 빼는 게 맞아요.

### 03-bulk-mirror.png (계정·조직 일괄 미러)
- 앱바 바로 아래 카드(아마 검색창)가 위쪽이 잘린 채 걸쳐 있어요. 스크롤 중에 찍힌 화면일 수도 있지만, 앱바와 내용 사이 경계가 없어서 잘려 보이는 게 지저분해요. 스크롤할 때 앱바에 구분선이나 그림자를 주세요.
- 이미 등록된 레포가 회색 체크박스로 표시돼요. "선택했지만 비활성"으로 읽혀서 혼란스러워요. 체크박스를 빼고 "등록됨" 배지만 남기거나, 목록 맨 아래로 내려 주세요.
- 필터 칩 "fork 제외 / archived 제외"는 영어와 한국어가 섞여 있어요. "포크 숨기기 / 보관된 레포 숨기기"로 바꿔 주세요. "fork 제외"가 켜져 있는데 "16개 중 16개 표시"라서 필터가 작동하는지 확신이 들지 않아요.
- 레포 설명(영문 + 이모지)이 제목보다 길고 진해서 눈이 설명 쪽으로 먼저 가요. 설명은 한 줄로 자르고 색을 한 단계 연하게 해 주세요.

### 04-repo-detail-mirror.png (미러 상세)
- 상단 "⇄ 읽기 전용 미러"가 파란 링크 색이라 눌러야 하는 것처럼 보여요. 상태 표시이니 회색 배지가 맞아요.
- "1.1 MB · 9분 전 측정"에서 "측정"이 무엇을 측정한 건지 모호해요. 용량이라면 "용량 1.1 MB"로 쓰고 측정 시각은 빼도 돼요.
- 원본 URL이 `.git` 앞에서 줄바꿈돼 `.git`만 다음 줄로 넘어가요. 한 줄 말줄임이나 가로 스크롤로 처리해 주세요.
- "마지막 확인"과 "마지막 업데이트" 시각이 똑같이 찍혀 있어 중복으로 보여요. 둘이 다를 때만 따로 보여 주세요.
- "지금 업데이트" 버튼이 화면 한가운데 큰 파란 버튼으로 있어요. 자동으로 따라가는 앱이라면 이건 보조 동작이에요. 주 동작처럼 강조할 이유가 없어요.
- "자동 업데이트에서 제외" 토글은 OFF가 "포함"이라는 이중 부정이에요. "자동 업데이트" ON/OFF로 바꿔 주세요.
- "PR ref 미러"의 3단 세그먼트(설정 따름/받기/받지 않기)는 저에게 너무 깊은 설정이에요.

### 05-repo-detail-local.png (로컬 상세)
- 미러 상세(`04`)에는 "정보 / 동기화 이력" 탭이 있는데 로컬 상세에는 탭이 없어요. 같은 "레포 상세"인데 구조가 달라서 낯설어요.
- clone URL이 "field\n-notes.git"으로 단어 중간에서 끊겨요. 주소 박스와 "clone 명령" 박스가 내용 대부분이 같아서 중복으로 보여요. 명령 하나만 두고, 주소만 복사하는 버튼을 따로 다는 편이 깔끔해요.
- "clone 주소"는 소문자 영어 섹션 제목이라 다른 한국어 제목(정보, 관리) 사이에서 튀어요.
- "마지막 push 9분 전 · 192.168.31.101"처럼 IP를 그대로 보여 주는 건 의미가 약해요. 기기 이름("내 노트북")을 보여 줄 수 있으면 훨씬 좋아요.
- "관리" 섹션의 "레포 삭제" 빨간색 처리와 위치는 좋아요.

### 06-qr.png (QR)
- QR은 크고 선명해서 좋아요.
- 주소가 두 번 반복돼요(URL과 git clone 명령). 둘 다 가운데 정렬에 단어 중간 줄바꿈이라 읽기 힘들어요.
- 화면 아래 40%가 비어 있어요. 이 자리에 "복사"와 "공유" 버튼을 두면 딱 맞아요. 지금은 이 화면에서 할 수 있는 일이 없어요.
- "주소에는 계정 정보가 들어가지 않아요" 문구가 너무 연하고 작아요. 중요한 정보라면 조금 더 진하게 해 주세요.

### 07-settings.png (설정)
- "인증 끄기" 토글은 OFF가 "인증 켜짐"이라는 이중 부정이에요. "접속 비밀번호 사용" ON이 자연스러워요.
- "같은 네트워크에서 읽기는 인증 없이"는 제목이 문장이에요. 설명문의 "수업할 때 유용해요"는 갑자기 맥락이 튀어서 웃음이 났어요. 예시라면 "팀원과 함께 볼 때"처럼 더 일반적인 상황이 좋아요.
- "연결 경로별 보안"은 카드 밖에 회색 문단 5줄로 놓여 있어요. 정보로서 중요하지만 읽히지 않는 위치와 스타일이에요. 이 정보는 서버 카드나 외부 접속 설정 옆에 붙어 있어야 해요.
- 섹션 제목 "외부 접속 (ngrok)"에 서비스 이름이 그대로 들어가 있어요. 사용자는 "밖에서도 접속하기"가 궁금한 거지 ngrok이 궁금한 게 아니에요.

### 08-storage.png (저장 공간)
- 가장 완성도 높은 화면이에요. 위계, 여백, 숫자 정렬이 모두 깔끔해요.
- "하한"은 생소한 단어예요. "남은 공간이 1 GB보다 적으면 자동 업데이트를 멈춰요"처럼 문장 하나로 충분해요.
- 각 행의 "13분 전 측정"은 모든 행에서 반복되는 노이즈예요. 상단에 한 번만 보여 주세요.
- "전체 백업 (zip)" 회색 버튼은 위아래 카드 사이에서 위치가 애매해요. 앱바 액션이나 화면 하단으로 옮기면 좋겠어요.

### 09-web-repo-list.png (웹 레포 목록)
- 필터(전체/미러/로컬/문제)와 정렬(최근순/이름순)이 같은 모양 버튼 6개로 한 줄에 있어요. 무엇이 선택돼 있는지 표시도 없어요. 필터는 세그먼트로, 정렬은 드롭다운으로 나눠 주세요.
- 미러마다 "원본 정상" 초록 배지가 붙어서 목록이 초록 배지로 도배돼요. 정상은 기본 상태이니 문제가 있을 때만 배지를 보여 주세요.
- 메타 줄 "미러 github.com/... 업데이트 8분 전 master 10.0 KB"에 구분자가 없어서 단어가 붙어 보여요. 앱처럼 가운데 점(·)을 넣어 주세요.
- 화면이 넓은 데 비해 행이 단조로워요. 1,500px 가까운 행에 정보는 왼쪽 절반에만 몰려 있어요.
- 헤더 문구 "읽기 전용"이 로컬 레포는 push 가능하다는 사실과 충돌해요. "웹에서는 보기만 가능"처럼 범위를 밝혀 주세요.

### 10-web-repo-home.png (웹 레포 홈)
- GitHub와 같아서 편해요. README 렌더링도 깔끔해요.
- 우상단 "Clone" 버튼과 오른쪽 "Clone" 카드가 같은 일을 두 번 해요. 하나만 남겨 주세요.
- 정보 카드의 "main"만 모노스페이스 폰트라 다른 값들과 기준선이 어긋나 보여요.
