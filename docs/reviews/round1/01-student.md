# mobilegit 1차 사용자 리뷰 — 컴공 3학년 (23세)

> 리뷰어: 토스·당근·카카오뱅크·노션·디스코드를 매일 쓰는 학생. 과제와 토이 프로젝트를 GitHub에 올리지만 git은 `add / commit / push / pull / clone` 정도만 씀.
> 본 화면: `docs/qa/round1/screenshots/` 01~14 전부.

---

## 1. 첫인상: 토스나 당근처럼 깔끔하고 현대적인가?

**대체로 그렇다.** 개발자 도구치고는 꽤 예쁜 편이에요. 솔직히 "폰을 git 서버로 쓰는 앱"이라길래 터미널 같은 회색 화면을 예상했는데, 생각보다 훨씬 토스 쪽이에요.

좋은 점
- **둥근 흰 카드 + 연회색 배경 + 파란 포인트색** 조합이 토스, 카카오뱅크랑 결이 같아요. `01-main`의 서버 카드는 토스 홈의 "내 계좌" 카드처럼 생겨서 바로 눈에 들어와요.
- **"~해요"체 문구** ("탭하면 복사돼요", "시간·용량을 많이 써요")가 친근해요. 토스 톤 그대로라 거부감이 없어요.
- `08-storage`는 거의 토스 "자산" 화면 같아요. 큰 숫자 하나(4.1 MB) + 막대 그래프 + 큰 순 정렬. 이 화면이 제일 완성도 높아 보였어요.
- 웹(`10`, `11`, `12`)은 GitHub랑 거의 똑같이 생겨서 배울 게 없어요. 이건 진짜 장점이에요.
- 다크 모드(`13`, `14`)도 색이 탁하지 않고 깔끔하게 잘 나왔어요.

어색한 점
- **글자가 너무 많아요.** 토스는 한 화면에 말하는 게 하나인데, 이 앱은 카드마다 설명문이 2~3줄씩 붙어 있어요 (`01`, `02`, `04`, `07`). 디자인은 토스인데 문구 양은 설정 앱 같아요.
- **용어가 그대로 노출돼요.** ref, PR ref, refs/pull/\*, HEAD, 원격 자격 증명, git bundle, WireGuard, ngrok… 디자인은 일반인용인데 말은 git 고수용이라 따로 노는 느낌이에요.
- 메인 첫 화면 절반을 IP 주소 카드가 차지해요. 정작 제일 중요한 "내 레포 목록"은 스크롤해야 보여요.

## 2. 화면만 보고 뭘 하는 앱인지 알 수 있나?

**반쯤 알겠어요.** "서버 켜짐 + IP 주소 + 레포 목록"을 보면 "폰이 서버구나"까지는 감이 와요. 그런데 아래는 헷갈렸어요.

- **"미러"와 "로컬"의 차이가 설명이 없어요.** `01-main` 필터에 "미러 12 / 로컬 3"이 있는데, 처음 보면 무슨 기준인지 몰라요. `04`에서 "읽기 전용 미러", `05`에서 "로컬 레포 · push 가능"을 보고 나서야 이해했어요.
- **로컬 레포는 어떻게 만드는지 모르겠어요.** "레포 추가" 버튼을 누르면 미러 추가(`02`)가 나오는 것 같은데, 로컬 레포는 `05`에 "PC에서 push"로 만들었다고만 나와요. "PC에서 push하면 자동으로 생겨요"라는 걸 화면 어디에서도 못 봤어요. 제 입장에선 이게 제일 궁금한 기능인데 찾을 수가 없어요.
- **PC에서 어떻게 연결하지?** `01`의 "git으로는 <주소>/<레포>.git"이 사실상 유일한 안내예요. `git remote add`를 써야 하는지, clone을 해야 하는지 초보는 모를 거예요.
- **"계정·조직 일괄 미러"(`03`)는 어디서 들어가는지 모르겠어요.** 기능은 제일 매력적인데(내 GitHub 레포 전체 백업!) 메인에 입구가 안 보여요. 아마 ⋮ 메뉴나 레포 추가 안에 숨어 있는 듯.
- **저장 공간(`08`)도 어디서 들어가는지 안 보여요.** 메인에 설정 아이콘과 ⋮만 있어요.
- **웹 상단 "읽기 전용"** (`09`~`12`): 로컬 레포는 push 가능하다면서 웹 헤더엔 "폰 속 git 서버 · 읽기 전용"이라고 써 있어서, 서버 전체가 읽기 전용인 줄 알았어요. "웹에서는 보기만 가능"이라는 뜻 같은데 오해하기 쉬워요.
- 웹 오른쪽 위 모니터 아이콘은 뭔지 모르겠어요 (테마 전환?).

## 3. 화면별로 걸리는 점

### 01-main.png (메인)
- 서버 카드가 너무 커요. 레포가 화면 아래쪽 1/3부터 시작해요. 서버가 켜져 있으면 한 줄로 접히면 좋겠어요.
- "탭하면 복사돼요. 브라우저로 열면 웹 화면, git으로는 <주소>/<레포>.git" — 한 문장에 정보가 세 개예요. 그리고 `<주소>/<레포>.git`이 줄바꿈되면서 "<주 / 소>"로 잘려요.
- 주소 옆 QR 아이콘: PC 브라우저로 열 주소인데 왜 QR인지? 폰끼리 공유할 때인가?
- "배터리 최적화 해제 필요" 칩: 노란색이라 눈엔 띄는데 뭘 눌러야 하는지(칩을 누르면 설정으로 가는지) 모르겠어요. 그리고 왜 필요한지 설명이 없어서 약간 무서워요.
- "레포 추가" 플로팅 버튼이 마지막 카드의 용량 글자를 가려요 (`field-notes ... 5.9 KB` 위). `13-main-dark`에선 "5.9 KB"가 실제로 잘려 보여요.
- git-consortium에만 ⋮ 버튼이 있고 나머지 카드엔 없어요. 일관성이 깨져 보여요 (누른 상태 캡처일 수도 있지만).
- "문제 있음 0" 필터는 0이면 굳이 안 보여도 될 것 같아요.
- 미러 아이콘(⇄)과 로컬 아이콘(폴더)은 구분은 되는데, 웹(`09`)에선 미러 아이콘이 ↻(새로고침 모양)이라 앱이랑 달라요.

### 02-add-mirror.png (미러 추가)
- 제목 "미러 추가" — 초보한테 "미러"는 낯선 단어예요. "GitHub 레포 백업하기" 같은 말이 훨씬 쉬워요.
- `/tree/main`이 붙은 주소를 붙여넣어도 `.git` 주소로 알아서 고쳐 주는 건 **정말 좋아요.** 이런 거 토스 같아요.
- "접근 가능 · ref 26개 받기 · PR ref 34개 제외 · 기본 브랜치 main" — ref가 뭔지 모르는 사람이 대부분일 거예요. "브랜치·태그 26개, 기본 브랜치 main" 정도면 충분해요.
- "PR ref도 받기" 토글은 기본 화면에 있을 필요가 없어요. "고급 설정"으로 접어 주세요.
- "원격 자격 증명" — 번역투예요. "비공개 레포라면 로그인 정보" 정도가 자연스러워요.
- "주소: <폰 주소>/strip-ansi.git" — 꺾쇠 플레이스홀더가 그대로 나와요. 실제 IP를 넣어 주면 더 좋겠어요.
- 입력칸이 4줄 높이인데 대부분 비어 있어요. "(여러 줄 가능)"이 여러 개 동시 추가라는 뜻인지 바로 안 와요.
- 하단 "추가" 버튼만 있고 예상 용량이 안 보여요. `03`처럼 "약 49 KB" 같은 걸 보여주면 안심돼요.

### 03-bulk-mirror.png (계정·조직 일괄 미러)
- 맨 위에 잘린 카드(입력칸?)가 살짝 보여서 스크롤 상태가 어색해요.
- "fork 제외" / "archived 제외" 칩: 어느 쪽이 켜진 상태인지 헷갈려요. 회색 채움 = 켜짐인가요? 체크 표시를 넣어 주세요. 그리고 영어+한글 섞임.
- 이미 등록된 레포가 회색 체크로 나오는 건 좋은데, 체크박스처럼 보여서 눌러서 해제할 수 있을 것 같아요. "등록됨" 배지만 두고 체크박스는 빼는 게 나아요.
- 하단 "선택 111 KB · 남은 공간 97.6 GB" + "2개 등록" 버튼은 **아주 좋아요.** 당근 거래 확정 버튼처럼 명확해요.
- "16개 중 16개 표시"는 필터를 켰는데도 16/16이면 필터가 안 먹은 것처럼 보여요.

### 04-repo-detail-mirror.png (미러 상세)
- "지금 업데이트"와 "변경 확인만 하기" 차이가 애매해요. fetch만 하고 반영 안 한다는 건가요? 초보는 그냥 "업데이트" 하나면 돼요.
- "마지막 확인"과 "마지막 업데이트"가 같은 시각이라 둘 다 있을 필요가 있나 싶어요. 다를 때만 둘 다 보여주면 될 듯.
- "수정하려면 로컬 레포로 분리하세요" — 분리 버튼이 이 근처에 없어요. ⋮ 안에 있나요? 문구 바로 옆에 버튼을 주세요.
- "자동 업데이트에서 제외" — 부정형 토글이라 켜면 꺼지는 거라 헷갈려요. "자동 업데이트" 켜짐/꺼짐으로 바꿔 주세요.
- "PR ref 미러" 3단 세그먼트(설정 따름/받기/받지 않기)는 너무 전문가용이에요. 고급 섹션으로.
- 상단 "1.1 MB · 9분 전 측정" — "측정"이라는 말이 어색해요.
- 탭(정보 / 동기화 이력)이 있는데 `05` 로컬 상세엔 탭이 없어요. 같은 "레포 상세"인데 구조가 달라서 다른 앱 같아요.

### 05-repo-detail-local.png (로컬 상세)
- clone 주소와 clone 명령이 거의 같은 내용으로 두 번 나와요. 명령 하나만 있어도 충분해요.
- "git이 물어보면 접속 계정을 입력하세요" — 그 계정이 뭔지(사용자 이름 git, 비밀번호는 설정에서…) 여기서 바로 알려주면 좋겠어요. 처음 push할 때 100% 여기서 막힐 것 같아요.
- 이미 PC에 있는 프로젝트를 여기로 올리는 법(`git remote add phone ...`)이 없어요. 제 사용 시나리오는 clone보다 이게 먼저예요.
- "마지막 push · 192.168.31.101" — IP보다 "내 PC" 같은 이름이면 좋겠어요(어려우면 그냥 숨겨도 됨).
- "레포 삭제"가 "내보내기" 바로 아래 같은 카드에 붙어 있어요. 빨간색이긴 하지만 실수로 누를까 봐 불안해요. 따로 떼어 맨 아래로.

### 06-qr.png (clone 주소 QR)
- 누구한테 보여주는 QR인지 모르겠어요. PC는 QR을 못 찍잖아요. 친구 폰? 태블릿?
- 주소가 가운데 정렬 고정폭 글꼴로 `field` / `-notes.git` 처럼 단어 중간에서 잘려요. 복사 버튼도 없어요.
- 화면 아래 절반이 텅 비어 있어요. 복사/공유 버튼을 두면 좋겠어요.

### 07-settings.png (설정)
- "인증 끄기" 토글이 너무 쉽게 눌릴 위치에 있어요. 경고 문구는 있지만 위험한 설정이니 아래쪽으로 내리거나 확인 창이 필요해요.
- "같은 네트워크에서 읽기는 인증 없이 … 수업할 때 유용해요" — 이 문구는 좋아요! 사용 상황을 말해주니까 바로 이해돼요. 다른 설정도 이런 식이면 좋겠어요.
- "연결 경로별 보안" 박스: 평문 HTTP, WireGuard, ngrok… 저는 대충 알지만 친구들은 못 읽을 거예요. "와이파이: 같은 와이파이 사람이 엿볼 수 있음 / Tailscale: 안전 / ngrok: 인터넷 누구나 시도 가능"처럼 신호등 색(초록·노랑·빨강)으로 줄여 주세요.
- 비밀번호는 "재설정"만 있는데, 처음 설치할 때 비밀번호가 뭐였는지 모르는 사람은 어떡하죠? 초기 비밀번호 안내가 필요해요.

### 08-storage.png (저장 공간)
- 제일 잘 만든 화면. 그대로 두세요.
- "하한"이라는 단어만 어색해요. "여유 공간이 1 GB 아래로 떨어지면 자동 업데이트를 멈춰요" 정도로.
- 레포 카드를 누르면 상세로 가는지 표시(›)가 없어요.

### 09-web-repo-list.png (웹 레포 목록)
- GitHub 느낌이라 익숙해요. 좋음.
- 오른쪽 필터 버튼 6개(전체/미러/로컬/문제/최근순/이름순)가 같은 모양이라 필터와 정렬이 섞여 보이고, 지금 뭐가 선택됐는지 안 보여요.
- 화면이 넓은데 한 줄에 정보가 짧아서 오른쪽이 텅 비어요.
- "원본 정상" 초록 배지가 미러마다 다 붙어 있어서 오히려 노이즈예요. 문제 있을 때만 빨갛게 띄우면 충분해요.

### 10-web-repo-home.png (웹 레포 홈)
- GitHub 레포 화면이랑 거의 같아서 바로 쓸 수 있어요. README 렌더링 깔끔.
- 오른쪽 위 "Clone" 버튼과 오른쪽 사이드 "Clone" 카드가 중복이에요.
- 사이드 정보의 "기본 브랜치 main"만 고정폭 글꼴이라 정렬이 살짝 어긋나 보여요.

### 11-web-file-view.png (웹 파일 보기)
- 코드 하이라이트, 줄 번호, 복사, 원본 다운로드까지 있어서 충분해요.
- 23번 줄처럼 긴 줄이 오른쪽에서 잘려요. 가로 스크롤인지 잘림인지 모르겠어요. 줄바꿈 토글이 있으면 좋겠어요.

### 12-web-commit-log.png (웹 커밋 기록)

## 4. 바꿨으면 하는 점 (우선순위 순)

1. **"PC 프로젝트를 폰에 올리는 법" 안내를 만들어 주세요.**
   메인이나 레포 추가 화면에 "PC에 있는 프로젝트 올리기" 항목을 두고, 누르면 `git remote add phone http://IP:8080/<이름>.git` → `git push phone main` 두 줄을 복사 버튼과 함께 보여 주세요. 사용자 이름/비밀번호도 같은 화면에 표시. 지금은 로컬 레포 만드는 법이 화면 어디에도 없어요.

2. **용어를 쉬운 말로 바꾸고, 전문 옵션은 "고급"으로 접어 주세요.**
   - 미러 → "GitHub 백업" (또는 "따라가는 레포"), 로컬 → "내 레포"
   - ref 26개 → "브랜치·태그 26개"
   - 원격 자격 증명 → "로그인 정보 (비공개 레포만)"
   - PR ref 관련 토글/세그먼트(`02`, `04`)는 전부 "고급 설정" 아래로
   - 각 탭/필터에 처음 한 번 짧은 툴팁("미러 = GitHub 원본을 자동으로 따라가는 읽기 전용 사본")

3. **메인 화면 정보 순서 정리 (`01`, `13`).**
   서버 카드를 한 줄 요약(● 서버 켜짐 · 192.168.31.120:8080 [복사])으로 줄이고, 누르면 펼쳐지게. 레포 목록이 첫 화면에 최소 4~5개 보이게. 리스트 하단에 FAB 높이만큼 여백을 넣어 글자 가림 해결.

4. **숨은 기능 입구 꺼내기.**
   "레포 추가"를 누르면 바텀시트로 ① GitHub 주소로 백업 ② 계정 전체 백업 ③ PC 프로젝트 올리기 세 개를 보여 주세요. 저장 공간은 설정 안 또는 메인 상단에 아이콘으로.

5. **미러 상세(`04`) 단순화.**
   버튼은 "지금 업데이트" 하나만, "변경 확인만"은 ⋮로. "자동 업데이트에서 제외" → "자동 업데이트" 긍정형 토글. "로컬 레포로 분리" 버튼을 안내 문구 옆에 직접. 로컬 상세(`05`)와 탭 구조 통일.

6. **위험 동작 분리.**
   `05`의 "레포 삭제"를 별도 카드로 떼서 맨 아래에, `07`의 "인증 끄기"는 확인 창 + 아래쪽으로 이동.

7. **설정(`07`) 보안 설명을 신호등 형식으로.**
   긴 문단 대신 연결 방식별 색 아이콘 + 한 줄.

8. **웹 소소한 것들.**
   - 헤더 "읽기 전용" → "웹은 보기 전용"
   - `09` 필터 선택 상태 표시, 필터/정렬 분리, "원본 정상" 배지는 문제 있을 때만
   - `10` Clone 버튼 중복 제거
   - `11` 긴 줄 줄바꿈 토글
   - `12` 커밋 diff 보기, 아이콘 툴팁
   - 앱과 웹의 미러 아이콘 통일 (⇄ vs ↻)

9. **QR 화면(`06`)**: 용도 설명 한 줄 + 복사/공유 버튼, 주소 줄바꿈을 `/` 기준으로.

## 5. 이 앱을 쓰겠나요?

**7 / 10 — 써 볼 것 같아요. 다만 "GitHub 백업용"으로만요.**

- **쓰고 싶은 이유:** 서랍에 굴러다니는 옛날 폰을 내 GitHub 레포 전체 백업기로 쓸 수 있다는 게 꽤 끌려요. `03` 일괄 미러로 내 계정 레포 다 받아 두고 자동으로 따라가게 하는 건 "혹시 GitHub 계정 날아가면?" 걱정을 덜어 줘요. 웹 화면도 GitHub랑 똑같아서 학교 PC에서 바로 볼 수 있고요. 앱 디자인도 제가 평소 쓰는 앱들이랑 결이 같아서 거부감이 없어요.
- **점수를 깎은 이유:**
  - 정작 "PC에서 git 원격 저장소처럼 쓰기"는 어떻게 시작하는지 화면만 보고는 몰라요. 저 정도 git 실력이면 여기서 포기할 확률이 높아요. (-1.5)
  - ref, PR ref, 자격 증명, HEAD, WireGuard 등 용어 장벽. 토스처럼 생겼는데 말은 토스처럼 안 해요. (-1)
  - 와이파이 같은 곳에서만 되고, 밖에서는 Tailscale/ngrok을 따로 공부해야 하는 점. (-0.5)
- 1번(PC 프로젝트 올리기 안내)과 2번(용어 정리)만 해결되면 8~8.5점까지 줄 수 있어요. 친구들한테도 "옛날 폰으로 깃허브 백업 서버 만드는 앱"이라고 추천할 수 있을 것 같아요.
