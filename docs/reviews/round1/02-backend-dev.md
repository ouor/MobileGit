# mobilegit 1차 리뷰: 백엔드 개발자 (34세, 8년 차)

> 평소 쓰는 앱: GitHub(웹·모바일), GitLab, Slack, 토스, 당근. 빠르고 군더더기 없는 도구를 좋아합니다.
> 본 화면: 스크린샷 14장 (폰 01~08, 13 / 웹 09~12, 14)

---

## 1. 첫인상

**결론: 깔끔합니다. "개인이 만든 git 서버 앱"이 흔히 주는 리눅스 GUI 같은 느낌이 없습니다.** 토스 같은 둥근 흰 카드, 넉넉한 여백, 파란색 하나로 맞춘 강조색, 해요체 문구까지, 토스에서 쓰는 화면 문법을 그대로 가져왔습니다. 웹(09~12)은 GitHub 레포 화면 구조를 거의 그대로 따라 해서 처음 봐도 어디를 눌러야 할지 압니다.

좋은 점
- 웹 화면은 GitHub을 써 본 사람이라면 배울 게 없습니다. 브랜치 드롭다운, 빵부스러기 경로, 코드/커밋 탭, 오른쪽 Clone 박스, README 렌더링(10), 문법 강조(11) 모두 예상한 자리에 있습니다.
- 숫자를 정직하게 보여 줍니다. "ref 26개 받기 · PR ref 34개 제외 · 기본 브랜치 main"(02), "남은 공간 97.6 GB", "선택 111 KB"(03). 개발자는 이런 걸 좋아합니다.
- 보안 경고를 숨기지 않습니다. 07의 "연결 경로별 보안"에서 평문 HTTP라 계정이 보일 수 있다고 대놓고 말해 주는 건 신뢰가 갑니다.
- 다크 모드(13, 14)도 대충 색만 뒤집은 수준이 아니라 제대로 맞췄습니다.

어색한 점
- **폰 메인(01)이 "앱"보다는 "서버 관리 패널"처럼 보입니다.** 화면 위쪽 40% 정도를 서버 카드와 배터리 배너가 차지해서, 정작 레포는 2개 반만 보입니다. 토스 홈이 "내 돈"을 가장 위에 두는 것처럼, 이 앱의 주인공은 레포 목록이어야 합니다.
- 글자와 여백이 전체적으로 큽니다. 토스 정도의 크기인데, 이 앱을 쓰는 사람은 GitHub 모바일처럼 정보가 빽빽한 화면에 익숙합니다. 04, 07은 스크롤을 많이 해야 합니다.
- 웹 상단에 "폰 속 git 서버 · 읽기 전용"이라고 고정돼 있는데, 로컬 레포는 push가 됩니다. 처음 보면 "웹에서만 읽기 전용"이라는 뜻인지, 서버가 통째로 읽기 전용이라는 뜻인지 헷갈립니다.

## 2. 화면만 보고 무엇을 하는 앱인지 알 수 있나?

**반쯤은 알 수 있습니다.** 01에 "서버 켜짐", IP 주소, "미러 12 / 로컬 3"이 보이니 "폰에서 git 서버를 돌리고, 미러와 로컬 레포가 있구나"까지는 개발자라면 5초 안에 압니다. 그 다음부터 막힙니다.

헷갈리거나 찾기 어려운 것
- **로컬 레포를 어떻게 만드는지 안 보입니다.** 05를 보니 "만든 방법: PC에서 push"인데, 그럼 서버에 없는 이름으로 push하면 레포가 자동으로 생기는 건가요? 이게 이 앱의 핵심 기능인데, 01 어디에도 "PC에서 `git push <주소>/새이름.git` 하면 새 레포가 생겨요" 같은 안내가 없습니다. "레포 추가" 버튼을 누르면 "미러 추가" 화면(02)으로 가는 것 같아서 더 헷갈립니다.
- **"미러"와 "로컬"의 차이.** 개발자니까 알지만, 01 칩에서는 설명이 없습니다. 04에 가서야 "읽기 전용 미러라 push는 거부돼요"를 봅니다. 아이콘도 ⇄(미러)와 폴더(로컬)인데, ⇄는 "동기화 중"처럼 보입니다.
- **계정·조직 일괄 미러(03)로 가는 입구**를 화면에서 찾을 수 없습니다. 아마 "레포 추가" 안의 메뉴거나 01 오른쪽 위 ⋮ 안에 있을 텐데, 이 앱에서 가장 쓸모 있는 기능 중 하나를 숨겨 둔 셈입니다.
- **저장 공간(08)도 어디서 들어가는지 모르겠습니다.** 아마 ⋮ 메뉴인 것 같은데, 톱니바퀴와 ⋮가 나란히 있으면 무엇이 어디 있는지 매번 둘 다 열어 봐야 합니다.
- **"문제 있음"이 무슨 문제인지.** 0이라 다행이지만 원본이 삭제된 것인지, 인증 실패인지, 용량 부족인지 짐작이 안 됩니다.

## 3. 화면별로 눈에 걸리는 점

### 01-main.png (메인)
- 서버 카드가 너무 큽니다. 서버가 켜져 있으면 "● 서버 켜짐 · 192.168.31.120:8080 [QR] [토글]" 한 줄이면 충분합니다.
- 안내 문구 "탭하면 복사돼요. 브라우저로 열면 웹 화면, git으로는 <주소>/<레포>.git"이 매번 보입니다. 첫 실행 때 한 번이면 됩니다. 그리고 "<주"/"소>"로 줄바꿈이 꺾여 읽기 불편합니다.
- 배터리 배너 "배터리 최적화 해제 필요"는 노란색이라 눈에는 띄는데, 누르면 무엇이 되는지(설정으로 이동?) 알 수 없고, X가 있어서 그냥 닫아 버리고 싶어집니다. 이걸 닫으면 백그라운드 서버가 죽을 텐데 그 결과가 적혀 있지 않습니다.
- "레포 추가" FAB가 field-notes 카드의 "5.9 KB"를 가립니다(13 다크에서는 "5.9 KE"로 잘려 보임). 목록 아래 여백이 필요합니다.
- 맨 위 git-consortium에만 ⋮가 있고 나머지 카드에는 없습니다. 미러에만 있는 건지, 버그인지 헷갈립니다.
- 목록에서 미러가 원본보다 얼마나 뒤처져 있는지(마지막 확인 시각, 실패 여부)가 안 보입니다. GitHub 모바일처럼 "업데이트 4분 전"만으로는 정상인지 모릅니다. 실패하면 빨간 점 정도는 있어야 합니다.

### 02-add-mirror.png (미러 추가)
- `/tree/main`이 붙은 주소를 넣어도 `.git` 주소로 정리해 주는 건 아주 좋습니다. GitHub에서 주소창 그대로 복사하는 게 현실이라서요.
- 입력칸 라벨이 "Git 저장소 주소 (여러 줄 가능)"인데, 여러 줄을 넣으면 "등록 정보" 카드는 어떻게 되는지 궁금합니다. 한 줄일 때와 여러 줄일 때 화면이 다를 것 같은데 힌트가 없습니다.
- "원격 자격 증명"은 번역투입니다. "원본 접속 계정" 또는 "토큰" 정도가 낫습니다. "없음 (공개 레포)"는 좋습니다.
- "주소: <폰 주소>/strip-ansi.git"에서 실제 IP를 바로 보여 주면 됩니다. 이미 알고 있는 값이잖아요.
- 버튼 "추가"는 화면 아래 고정이라 엄지로 누르기 좋습니다. 토스식으로 잘 됐습니다.

### 03-bulk-mirror.png (계정·조직 일괄 미러)
- 스크린샷이 스크롤된 상태라 맨 위 입력칸이 잘려 있습니다. 스크롤하면 어떤 계정을 보고 있는지 사라지므로, 제목 옆에 "chalk (16)"처럼 고정해 주면 좋겠습니다.
- 이미 등록된 레포의 회색 체크박스가 "선택됐는데 비활성"처럼 보입니다. 체크박스 대신 "등록됨" 배지만 두고 체크박스 자리를 비우는 게 덜 헷갈립니다.
- "fork 제외"는 회색으로 채워져 있어서 켜진 것인지 꺼진 것인지 바로 안 읽힙니다. 01의 "전체" 칩과 같은 스타일이라 "선택됨"으로 읽히긴 하는데, 체크 아이콘이 있으면 확실합니다.
- 하단 "선택 111 KB · 남은 공간 97.6 GB"와 "2개 등록" 버튼은 아주 좋습니다.

### 04-repo-detail-mirror.png (미러 상세)
- "마지막 확인"과 "마지막 업데이트"가 같은 값인데 둘 다 "9분 전 (2026.10.25 12:22)"로 상대·절대 시각을 겹쳐 씁니다. 상대 시각만 두고 길게 누르면 절대 시각을 보여 주면 됩니다.

## 5. 쓰겠나요? 점수: 7 / 10

**쓸 겁니다. 단, "메인 도구"가 아니라 "보관함"으로요.**
