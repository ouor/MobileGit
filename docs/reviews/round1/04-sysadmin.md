# mobilegit 1차 리뷰: 52세 시스템 관리자

> 리뷰어: 중견기업 시스템 관리자 (사내 GitLab, NAS 담당). 노안이 있어서 폰 글꼴을 크게 해 놓고 씁니다. 평소 쓰는 앱은 은행 앱, 토스, 당근, 네이버, 카카오톡입니다.
> 본 화면: 폰 01~08, 13(다크) / PC 웹 09~12, 14(다크)

---

## 1. 첫인상

**토스 느낌이 납니다.** 연한 회색 바탕에 흰 카드를 얹고, 파란 버튼 하나만 강조하는 구성입니다. "탭하면 복사돼요", "푸시는 거부돼요" 같은 존댓말 안내도 토스 말투 그대로입니다. 그래서 개발 도구인데도 겁부터 나지는 않았습니다. 리눅스 서버 관리 화면처럼 회색 표가 줄줄이 나올 줄 알았는데 그렇지 않았습니다.

**좋은 점**
- 글꼴을 크게 해 둔 폰인데도 01-main의 `192.168.31.120:8080`이 크고 굵게 나옵니다. 제일 필요한 정보가 제일 큽니다. 은행 앱이 잔액을 크게 보여 주는 것과 같은 방식이라 좋습니다.
- 서버 상태는 초록 점, "서버 켜짐", 토글이 한 줄에 모여 있습니다. NAS 관리 화면보다 알아보기 쉽습니다.
- 08-storage는 당근의 "내 동네 설정"만큼 단순합니다. 큰 숫자 하나 밑에 레포별 막대가 큰 순서로 나와서 그냥 보면 이해됩니다.
- PC 웹(10, 11, 12)은 GitHub나 사내 GitLab과 배치가 거의 같아서 따로 배울 게 없었습니다.

**어색한 점**
- 01-main 위쪽 절반을 서버 카드와 배터리 경고가 차지합니다. 정작 "내 레포"는 화면 아래로 밀려나서 두 개 반만 보입니다. 토스 홈은 내 자산이 바로 보이는데 여기는 설정 화면을 먼저 보는 느낌입니다.
- 오른쪽 아래 "레포 추가" 버튼이 field-notes 줄의 용량 글자(5.9 KB)를 가립니다. 다크 모드(13)에서는 `5.9 KB`가 아예 `5.9 KE`처럼 잘려 보입니다. 사소해 보여도 이런 데서 "덜 다듬었다"는 인상이 남습니다.
- 영어와 한글이 섞여 있습니다. push, ref, PR ref, clone, fork, archived, HEAD 같은 말이 그대로 나옵니다. 저는 git을 알아서 괜찮지만, 토스처럼 쉬운 앱을 기대한 사람이라면 02와 04에서 막힐 겁니다.

## 2. 무엇을 하는 앱인지 한눈에 보이나

**반 정도만 보입니다.** 01-main을 보면 "폰이 서버구나"는 금방 압니다. "서버 켜짐"과 IP 주소가 크게 있으니까요. 그런데 이 앱이 하는 두 가지 일, 즉 **(가) GitHub 레포를 따라가며 보관(미러)** 하는 일과 **(나) PC에서 push 받는 개인 저장소(로컬)** 역할이 첫 화면에서는 "미러 12 / 로컬 3" 필터 칩으로만 구분됩니다. 처음 보는 사람은 그 둘이 무슨 차이인지 알 수 없습니다.

헷갈리거나 찾기 어려운 것:
- **로컬 레포는 어떻게 만드나?** 버튼 이름은 "레포 추가"인데 누르면 "미러 추가"(02)만 나옵니다. 로컬 레포는 PC에서 push하면 생긴다는 것을 05의 "만든 방법: PC에서 push"를 보고서야 알았습니다. 첫 화면이나 추가 화면에 "PC에서 바로 push하면 새 레포가 생겨요" 한 줄이 있어야 합니다.
- **저장 공간(08) 화면은 어디서 들어가나?** 01에는 톱니바퀴와 점 세 개 메뉴가 나란히 있습니다. 설정(07)은 톱니바퀴일 테니 저장 공간은 점 세 개 안에 있는 것 같습니다. 그런데 둘 다 "설정 비슷한 것"이라 어디를 눌러야 할지 매번 고민될 것 같습니다.
- **계정·조직 일괄 미러(03)** 는 아주 쓸모 있는 기능인데 어디서 들어가는지 화면만으로는 모르겠습니다.
- **PC 웹 맨 위 "읽기 전용"(09~12)**: 웹 화면이 읽기 전용이라는 뜻인지, 서버 전체가 읽기 전용이라는 뜻인지 애매합니다. 로컬 레포는 push가 되는데 바로 그 옆에 "읽기 전용"이라고 쓰여 있으니 처음엔 "push가 안 되나?" 했습니다.
- **웹 오른쪽 위 모니터 아이콘(09~12, 14)**: 무엇인지 모르겠습니다. 테마 전환 같은데 글자 설명이 없습니다.

## 3. 화면별로 걸리는 점

### 01-main.png (메인)
- 주소 아래 안내문 "브라우저로 열면 웹 화면, git으로는 <주소>/<레포>.git"이 회색 작은 글씨에 꺾쇠까지 섞여 있습니다. 노안인 저한테는 이 줄이 제일 안 읽힙니다. 정작 중요한 사용법이 제일 작습니다.
- "배터리 최적화 해제 필요" 칩은 눈에 잘 띕니다. 다만 X로 닫을 수만 있고 눌렀을 때 바로 설정으로 가는지는 모르겠습니다. 칩 자체를 눌러서 해결 화면으로 가게 해 주세요.
- 미러 아이콘은 ⇄인데 웹(09)의 미러 아이콘은 동그란 화살표(↻)입니다. 같은 것을 다른 그림으로 보여 줍니다.
- 첫 줄 git-consortium에만 점 세 개(⋮)가 있고 dotfiles 등에는 없습니다. 미러에만 메뉴가 있는 건지, 그냥 처음 줄만 보이는 건지 헷갈립니다.
- "인증 켜짐"은 좋은 정보지만 "로그인 필요" 정도로 쉬운 말을 같이 쓰면 좋겠습니다.

### 02-add-mirror.png (미러 추가)
- 붙여 넣은 `.../tree/main` 주소를 알아서 `.git` 원본 주소로 정리해 줍니다. 똑똑합니다. 등록 전에 "접근 가능" 초록 상자로 먼저 확인해 주는 것도 은행 앱의 "받는 분 확인"처럼 안심이 됩니다.
- "ref 26개 받기 · PR ref 34개 제외"는 git을 아는 저도 한 번 더 읽었습니다. "브랜치·태그 26개 받기"가 더 쉽습니다.
- "원격 자격 증명"은 번역투입니다. "원본 접속 계정(비공개 레포일 때)"이 좋겠습니다.
- "이 폰에서 쓸 이름" 아래 "주소: <폰 주소>/strip-ansi.git" 글씨가 작고 회색입니다.
- 남은 공간 97.6 GB를 추가 버튼 바로 위에 보여 주는 건 시스템 관리자 입장에서 아주 반갑습니다.

### 03-bulk-mirror.png (계정·조직 일괄 미러)
- 화면이 이미 스크롤된 상태라 맨 위 입력칸이 잘려 있습니다. 어떤 계정을 보고 있는지 제목에서 안 보입니다. 제목 밑에 "chalk 계정" 식으로 고정해 주세요.
- **이미 등록된 레포가 회색 체크로 표시**됩니다. 언뜻 보면 "선택됨"처럼 보여서 파란 체크와 헷갈립니다. 체크박스를 아예 빼고 "등록됨" 배지만 두는 게 낫겠습니다.
- "fork 제외" 칩은 회색으로 칠해져 있어 선택된 상태 같은데 "archived 제외"와 차이가 미묘합니다. 선택된 칩에는 체크 표시(✓)나 파란색을 써 주세요. 04 화면의 "✓ 설정 따름"처럼 하면 됩니다.
- 아래 "선택 111 KB · 남은 공간 97.6 GB"와 "2개 등록" 버튼은 아주 좋습니다. 무엇을 누르면 무슨 일이 생기는지 분명합니다.

### 04-repo-detail-mirror.png (미러 상세)
- "지금 업데이트"(큰 파란 버튼)와 "변경 확인만 하기"(글자 버튼)의 강약 구분이 좋습니다.
- "읽기 전용 미러라 push는 거부돼요. 수정하려면 로컬 레포로 분리하세요." 이런 친절한 설명이 마음에 듭니다. 그런데 "분리"는 어디서 하나요? 점 세 개 메뉴인 것 같습니다. 문장 안에 링크를 걸어 주세요.
- **"자동 업데이트에서 제외" 토글은 거꾸로 된 말**입니다. 꺼져 있으면 "제외 안 함", 곧 자동 업데이트를 한다는 뜻이라 두 번 생각해야 합니다. 07의 "인증 끄기"도 같은 문제입니다. 토글은 "자동 업데이트 [켜짐]"처럼 긍정형으로 써 주세요.
- "1.1 MB · 9분 전 측정"의 **"측정"** 이 어색합니다. "용량 9분 전 기준"이 자연스럽습니다. 08에도 "측정"이 반복됩니다.
- 원본 URL이 `https://github.com/chalk/chalk` 다음 줄에 `.git`만 떨어져 나와 있습니다. 주소는 끊는 위치가 이상하면 읽기 불편합니다.
- 맨 아래 "원격 자격 증명" 칸이 화면에 걸려 잘려 있어서 아래에 무엇이 더 있는지 감이 안 옵니다.

### 05-repo-detail-local.png (로컬 상세)
- 마지막 push 주소(192.168.31.101)까지 보여 줍니다. 관리자로서는 "누가 push했는지" 알 수 있어 아주 좋습니다.
- clone 주소가 `field` / `-notes.git`으로 **단어 중간에서 줄이 바뀝니다**. 06, 10, 14 웹 사이드바에서도 똑같습니다. 하이픈이 원래 있는 글자인지 줄바꿈 표시인지 헷갈려서 손으로 옮겨 칠 때 실수하기 딱 좋습니다. 줄을 바꾸지 말거나 `/` 뒤에서만 바꿔 주세요.
- 04(미러)에는 "정보 / 동기화 이력" 탭이 있는데 05(로컬)에는 탭이 없습니다. 로컬도 "push 이력" 탭이 있으면 좋겠습니다.
- "레포 삭제"가 빨간 글씨로 분리돼 있는 건 좋습니다. 그래도 "내보내기" 바로 밑이라 손가락이 미끄러질 수 있으니 간격을 더 두세요. 삭제 전에 레포 이름을 입력하게 하는 확인 창이 있기를 바랍니다.
- 와이파이 주소만 보이고 Tailscale 주소는 안 보입니다. 01에 Tailscale 안내가 있었으니 연결돼 있으면 여기도 보여 줘야 합니다.

### 06-qr.png (QR)
- QR은 크고 선명합니다. 다만 clone 주소를 **누가 QR로 찍는지** 모르겠습니다. 다른 폰이나 태블릿용인가요? 화면 아래에 "다른 기기 카메라로 찍으면 주소가 복사돼요" 정도의 한 줄이 필요합니다.
- 주소 글씨는 크지만 위 05와 똑같이 단어 중간에서 끊깁니다. git clone 줄은 회색 가운데 정렬이라 오히려 더 읽기 어렵습니다. 여기엔 복사 버튼도 없습니다.

### 07-settings.png (설정)
- **"연결 경로별 보안" 설명이 솔직해서 좋습니다.** "평문 HTTP라 같은 네트워크의 다른 기기가 접속 계정을 엿볼 수 있어요"라고 숨기지 않고 말해 줍니다. 관리자로서 신뢰가 갑니다. 그런데 이 중요한 내용이 회색 작은 글씨로 토글들 밑에 묻혀 있습니다. 카페 와이파이에서 쓰는 사람은 이걸 첫 화면(01)에서 봐야 합니다.
- "인증 끄기" 토글은 부정형이라 04와 같은 문제가 있습니다. "로그인 요구 [켜짐]"이 좋겠습니다. 그리고 이걸 켜면 누구나 push할 수 있으니 켤 때 확인 창이 꼭 있어야 합니다.
- "같은 네트워크에서 읽기는 인증 없이 … 수업할 때 유용해요"는 예시가 저 같은 사용자와 맞지 않아 어리둥절했습니다. "팀원에게 보여 줄 때"처럼 더 일반적인 예가 좋겠습니다.
- "부팅 후 서버 자동 시작"은 기본값이 꺼짐인데, 서버로 쓰는 앱이라면 켜짐이 기본이어야 하지 않나 싶습니다.
- 비밀번호를 다시 보여 주지 않는 건 맞는 설계입니다.

### 08-storage.png (저장 공간)
- 전체 화면 중 가장 깔끔합니다. 큰 숫자, 남은 공간, 하한값, 레포별 막대. 고칠 게 거의 없습니다.
- "하한: 1.0 GB 미만이면 … 멈춰요"는 좋은데 이 값을 어디서 바꾸는지 모르겠습니다. 줄을 누르면 바꿀 수 있게 해 주세요.
- 레포 줄을 누르면 해당 레포 상세로 가는지 모르겠습니다. 오른쪽 화살표(›)를 달아 주세요.
- "전체 백업 (zip)" 버튼이 회색이라 눌리는 버튼인지 잠깐 헷갈렸습니다. 백업은 중요한 기능이니 테두리라도 더 진하게 해 주세요.

### 09-web-repo-list.png (웹 레포 목록)
- GitHub 목록과 비슷해서 편합니다. "원본 정상" 초록 배지로 상태가 바로 보입니다.
- **필터 칩(전체·미러·로컬·문제)과 정렬 칩(최근순·이름순)이 한 줄에 똑같은 모양으로** 붙어 있습니다. 어느 것이 지금 선택된 건지도 안 보입니다. 정렬은 드롭다운으로 따로 떼고, 선택된 칩은 색을 칠해 주세요.
- 회색 보조 글씨(미러, github.com/…, 업데이트 11분 전, main, 1.1 MB)가 작고 흐립니다. 24인치 모니터에서 브라우저 확대 없이 보기 힘듭니다.
- 화면이 넓은데 오른쪽 절반이 비어 있습니다. 용량이나 마지막 업데이트를 오른쪽 정렬 열로 빼면 표처럼 비교하기 좋겠습니다.

### 10-web-repo-home.png (웹 레포 홈)
- 사내 GitLab과 배치가 같습니다. 파일 목록, README, 오른쪽 Clone·정보 칸. 바로 적응됩니다.
- 오른쪽 위 파란 "Clone" 버튼과 오른쪽 "Clone" 카드가 같은 일을 두 번 합니다. 하나만 있어도 됩니다.
- "push 11분 전"인데 최신 커밋은 "16시간 전"입니다. push 시각과 커밋 시각이 다른 건 git을 알면 이해되지만, 처음 보면 데이터가 이상한가 싶습니다.

### 11-web-file-view.png (웹 파일 보기)
- 줄 번호, 색 구분, 복사, 다운로드까지 다 있습니다. 좋습니다.
- 23번 줄 긴 주석이 오른쪽에서 잘립니다. 줄바꿈 켜기/끄기 버튼이 있으면 좋겠습니다.
- **"원본 다운로드"의 "원본"** 이 이 앱에서는 "GitHub 쪽 원본(upstream)"이라는 뜻으로도 쓰입니다(배지 "원본 정상"). 여기서는 "파일 그대로 받기(raw)"라는 뜻이라 같은 단어가 두 가지 의미를 가집니다. "파일 다운로드"로 바꿔 주세요.

## 4. 바꿨으면 하는 점 (우선순위 순)

1. **주소가 단어 중간에서 끊기지 않게** (05, 06, 04, 10, 14)
   이 앱의 핵심은 주소를 복사해서 쓰는 겁니다. `field` / `-notes.git`처럼 끊기면 잘못 옮겨 치기 쉽습니다. 가로 스크롤 한 줄로 두거나 `/` 뒤에서만 줄을 바꾸세요. QR 화면(06)에도 복사 버튼을 넣어 주세요.

2. **토글 문구를 긍정형으로** (04 "자동 업데이트에서 제외", 07 "인증 끄기")
   켜짐이 곧 "그 기능이 동작함"이 되게 해 주세요. "자동 업데이트 [켜짐]", "로그인 요구 [켜짐]". 인증을 끌 때는 확인 창을 띄워 주세요.

3. **보안 경고를 눈에 띄게** (07 → 01)
   평문 HTTP 경고가 설정 아래쪽 회색 글씨에 묻혀 있습니다. 공용 와이파이일 때 01 서버 카드에 노란 칩으로 "같은 와이파이의 다른 기기가 비밀번호를 볼 수 있어요"를 띄워 주세요. 관리자로서는 이게 기능보다 중요합니다.

4. **두 가지 레포 종류를 첫 화면에서 설명** (01, 02)
   "레포 추가"를 누르면 "GitHub 레포 보관하기(미러)", "계정 전체 보관하기(일괄)", "PC에서 새 레포 올리기(로컬): push 명령 안내" 세 가지 선택지가 나오게 해 주세요. 지금은 로컬 레포를 만드는 방법을 앱 안에서 찾을 수 없습니다.

5. **레포 목록을 위로 끌어올리기** (01, 13)
   서버 카드를 접을 수 있게 하거나 한 줄 요약("● 켜짐 · 192.168.31.120:8080 [복사]")으로 줄여 주세요. 레포 목록이 첫 화면에 최소 5개는 보여야 합니다. 그리고 FAB가 목록 글자를 가리지 않게 목록 아래쪽에 여백을 주세요.

6. **작고 흐린 보조 글씨 키우기** (01 안내문, 02 "주소: <폰 주소>…", 09·14 웹 보조 정보)
   중요한 사용법이 들어 있는 줄은 회색 대신 본문 색으로, 글씨도 한 단계 크게 해 주세요. 웹은 보조 글씨 대비를 높여 주세요.

7. **선택 상태를 분명히** (03 칩과 회색 체크, 09 필터·정렬 칩)
   선택된 칩은 색 칠하고 ✓ 표시. 이미 등록된 레포는 체크박스 대신 배지만. 웹은 필터와 정렬을 분리해 주세요.

8. **용어 정리**
   - "측정" → "기준" (04, 08)
   - "원격 자격 증명" → "원본 접속 계정" (02, 04)
   - "ref 26개" → "브랜치·태그 26개" (02)
   - 웹 "원본 다운로드" → "파일 다운로드" (11)
   - 웹 머리글 "읽기 전용" → "웹 보기 전용 (push는 git으로)" (09~12)

9. **아이콘에 글자 붙이기** (01 미러 아이콘을 웹과 통일, 12 커밋 옆 아이콘, 09 모니터 아이콘)
   같은 개념에는 앱과 웹에서 같은 그림을 쓰고, 뜻이 애매한 아이콘에는 짧은 글자를 붙여 주세요.

## 5. 쓰겠나요?

**점수: 7 / 10**

**쓸 겁니다. 다만 개인용으로만.**

- 집에서 굴리는 NAS에 Gitea 깔고 관리하는 게 늘 귀찮았습니다. 서랍에 있는 안 쓰는 폰을 충전기에 꽂아 두고 GitHub 레포를 보관해 두는 용도라면 딱입니다. 03 일괄 미러, 08 저장 공간, 04 "변경 확인만 하기"는 관리자가 원하는 걸 정확히 알고 만든 기능입니다.
- 화면은 토스처럼 정돈돼 있고, 무엇이 위험한지(평문 HTTP, push 거부 이유) 솔직하게 써 놓은 점이 믿음직합니다. 웹 화면은 사내 GitLab 쓰던 손에 그대로 맞습니다.
- 3점을 뺀 이유는 이렇습니다. 첫째, 주소 줄바꿈과 부정형 토글처럼 **매일 쓰는 곳에서 실수를 부르는 부분**이 있습니다. 둘째, 로컬 레포 만드는 방법 같은 **핵심 사용법이 화면에 드러나지 않습니다**. 셋째, 노안인 저한테는 **중요한 안내가 작은 회색 글씨**로 되어 있는 곳이 여러 군데입니다.
- 회사 업무용으로는 평문 HTTP와 "폰이 꺼지면 서버도 꺼진다"는 점 때문에 아직 못 씁니다. 그건 이 앱의 목적이 아니니 감점하지는 않았습니다.

위 4번의 1~5번만 고쳐도 8점 이상 줄 수 있습니다.
