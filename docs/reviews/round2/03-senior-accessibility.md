# 2차 리뷰 03 — 시니어 백엔드 개발자, 접근성 관점

리뷰어: 50대 백엔드 개발자. git은 매일 씁니다. 노안이 있어서 폰 글꼴을 크게 두고 씁니다. 대비, 터치 영역, 색에만 기대는 정보를 먼저 봅니다.
근거: `docs/qa/round2/screenshots/`의 화면 번호(01–30, 21b, 29b).

> 전제: 스크린샷은 기본 글꼴 크기로 찍은 것 같습니다. 제가 실제로 쓰는 큰 글꼴(130% 이상)에서는 아래 지적한 잘림과 겹침이 더 심해질 겁니다. 큰 글꼴과 표시 크기를 키운 상태로 한 번 더 찍어 주세요.

## 첫인상

- 내용은 git을 아는 사람 눈높이에 정확히 맞습니다. 히스토리 바뀜, 브랜치 삭제됨, 태그 이동됨, `refs/archive/*` fetch 명령(06, 07)은 제가 알고 싶은 걸 그대로 말해 줍니다. "force-push 당해도 이전 커밋이 남는다"는 약속이 화면에서 바로 보입니다.
- 앱 화면의 글자는 대체로 크고 시원합니다. 제목, 레포 이름, 버튼은 노안인 제가 봐도 편합니다(01, 12, 16).
- 다만 화면마다 **회색 작은 글씨**가 많습니다. 요약 줄, SHA, 보조 설명, 웹 화면 대부분이 그렇습니다. 중요한 정보가 하필 그 회색 글씨에 들어 있는 경우가 있어서 아쉽습니다.
- 메인 목록에서 상태 줄이 잘리거나(02, 26, 28) "레포 추가" 버튼이 행을 가리는 것(04, 20, 21b, 26)이 먼저 눈에 걸렸습니다.

## 좋은 점

1. **상태를 색만으로 알리지 않습니다.** 실패, 원본 없음, 지연, 히스토리 바뀜 배지에 아이콘과 글자가 함께 있습니다(01–04). 색약인 동료도 구분할 수 있습니다. 06의 변화 종류 칩도 글자가 들어 있어서 색이 겹쳐도 읽힙니다.
2. **상태 문구가 구체적입니다.** "6시간 주기인데 3일째 확인 못 함"(04)은 숫자 두 개로 상황을 다 설명합니다. "업데이트 실패 · 네트워크 오류"와 "원본 없음"을 진짜 404일 때만 나누는 것(26–28)도 맞는 판단입니다. 일시적인 오류로 "원본 없음"이 뜨면 괜히 놀랍니다.
3. **보존 기록 화면(07)이 잘 만들어졌습니다.** 시각별 묶음, 종류, 브랜치 이름, SHA, 커밋 제목, "지금 원본" 값, 바로 복사할 수 있는 fetch 명령이 한 화면에 있습니다. "push로 만들거나 바꿀 수 없어요"라는 한 줄 덕분에 믿음이 갑니다.
4. **위험한 선택지의 기본값이 안전합니다.** 18과 25에서 채워진 큰 버튼이 "취소"이고, 위험한 "그래도 진행"은 맨 아래에 빨간 글자로 따로 있습니다. 실수로 엄지가 미끄러져도 안전한 쪽이 눌립니다.
5. **분리 시트(16)가 "남는 것 / 바뀌는 것"으로 나뉘어 있습니다.** 되돌릴 수 없다는 말이 정확한 위치에 있고, "(권장)" 표시도 명확합니다.
6. **계정 안내가 친절합니다.** "사용자 이름에 git, 비밀번호에 이 앱의 비밀번호… GitHub 계정이 아니에요"(12, 15). 처음 쓰는 사람이 가장 많이 막힐 곳을 미리 막았습니다.
7. **재시작 뒤 외부 공개가 꺼진다는 사실을** 알림(21)과 배너(21b) 양쪽에서 알려 줍니다. 서버 알림의 "ngrok: 토큰 확인 필요"(30)도 짧고 정확합니다.
8. 웹 모바일 폭(09)에서 표를 카드로 바꾸고 가로 스크롤을 없앤 점이 좋습니다.

## 헷갈리거나 불편한 점

1. **상태 줄이 잘립니다.** 02, 26, 28에서 "미러 · 업데이트 실패 · 네트워크 오류 · 방…"으로 끝납니다. 언제부터 실패했는지가 잘린 부분에 있는데, 그게 가장 궁금한 정보입니다. 큰 글꼴에서는 "네트워크 오류"까지 잘릴 겁니다. 줄이 넘치면 잘라 내지 말고 두 줄로 내려 주세요.
2. **"레포 추가" 버튼이 목록을 가립니다.** 04의 chalk 행 "1."과 20·21b·26의 용량 숫자가 FAB 뒤로 숨고, 오른쪽 화살표도 가려집니다. 목록 아래에 FAB 높이만큼 여백을 두거나, 스크롤할 때 FAB를 줄여 주세요.
3. **필터 칩 줄의 오른쪽 끝이 잘려 있습니다.** 01–05, 14, 26–28 모두 "주의 필요 1"이 화면 끝에 걸려 있고, 05에서는 "주의 필요 13"이 경계에 닿아 있습니다. 옆으로 밀 수 있다는 표시가 없습니다. 칩이 4개뿐이니 24처럼 줄바꿈하는 게 낫습니다.
4. **요약 줄 줄바꿈이 어색합니다.** 04에서 둘째 줄이 "· 마지막 확인 1시간 전"처럼 구분점으로 시작합니다. 구분점이 줄 앞에 오면 앞 줄과 이어진다는 걸 놓치기 쉽습니다.
5. **경고 배너가 쌓입니다.** 05에서는 "배터리 최적화를 꺼 주세요"와 "백그라운드 확인이 멈춘 것 같아요"가 동시에 떠서 레포 목록이 화면 아래로 밀려납니다. 같은 원인이니 하나로 합쳐 주세요. 그리고 05에서는 원래 있던 요약 줄("미러 13개 · 정상 …")이 사라집니다. 일부러 그런 거라면 괜찮지만, 다른 화면과 달라서 처음에는 뭔가 빠진 줄 알았습니다.
6. **05에서 "주의 필요 13"이 지나치게 무겁습니다.** 백그라운드가 멈춰서 13개가 모두 "지연"이 되면 목록 전체가 주황색이 됩니다. 원인은 하나(백그라운드 멈춤)인데 문제가 13개인 것처럼 보입니다.
7. **"설정에서 authtoken을 확인하세요"가 설정 화면 안에 나옵니다(29).** 이미 설정 화면에 있으니 "아래 authtoken을 확인하세요"라고 쓰거나, 문구를 누르면 바로 authtoken 행으로 가게 해 주세요.
8. **ngrok 토글이 실패 상태인데 켜진 모양입니다(29).** 파란색 켜짐 토글 위에 "실패"가 붙어 있어서 지금 공개 중인지 아닌지 한눈에 알 수 없습니다. 토글 옆에 "연결 안 됨" 같은 상태를 글자로 붙여 주세요.
9. **주기 대화상자(22)에 "닫기"만 있습니다.** 라디오를 누르는 순간 저장되는 건지, 닫기를 눌러야 저장되는 건지 알 수 없습니다. 대화상자 아래의 "자동 업데이트 조건은 아래 스위치에서 바꿔요"도, 요약 줄에 "와이파이에서만"이라고 써 있는데 스위치는 켬/끔뿐이라 조건을 어디서 바꾸는지 모르겠습니다.
10. **"분리하기"(13)가 문단 옆 글자 링크라서** 버튼처럼 보이지 않고 손가락으로 누르기도 좁습니다. 되돌릴 수 없는 동작으로 들어가는 입구이니 테두리가 있는 버튼으로 만들어 주세요.
11. **보존 기록 화면(07)의 시간 표기가 섞여 있습니다.** dark-mode와 v1.1.0은 "커밋 2026.10.12"인데 main만 "커밋 5일 전"입니다. 같은 표 안에서는 하나로 맞춰 주세요. 웹(08)은 "2026. 10. 20. 오후 1:15", 앱(06)은 "2026.10.25 16:35"로 형식이 또 다릅니다.
12. **알림이 잘립니다(17).** "qa 폴더에 mobilegit-backu…"에서 파일 이름이 잘리고, 알림 아이콘이 기본 안드로이드 로봇 그림입니다. 알림 목록에서 이 앱을 찾기 어렵습니다.
13. **14의 "탭하면 주소가 복사돼요"**라는 설명과 복사 아이콘이 함께 있어서, 주소 글자를 눌러야 하는지 아이콘을 눌러야 하는지 헷갈립니다. 둘 다 된다면 설명을 "주소나 복사 버튼을 누르면…"으로 바꿔 주세요.

## 시각, 레이아웃, 접근성 문제

**대비**
- 회색 보조 글씨의 대비가 약합니다. 메인 요약 줄(01), SHA(06, 07의 `6720d8f`, `12e8ab8 → 4aa4393`), 각 행의 보조 줄, 설정 설명(19), 13 하단 섹션 제목 "고급", "관리"가 그렇습니다. 연한 회색 배경(#F2F3F5 정도) 위의 중간 회색은 노안에는 번져 보입니다. 특히 SHA는 git 사용자가 실제로 옮겨 적는 값이라 본문 색으로 올려 주세요. 최소 4.5:1을 맞춰 주세요.
- 주황 계열 글씨: 01의 "미러 · 히스토리 바뀜 · 방금 보존", 04의 "6시간 주기인데…", 배지 "히스토리 바뀜", "지연", "태그 이동됨"이 연노랑 배경 위의 갈색/주황입니다. 굵게 쓴 제목은 괜찮지만 보통 굵기의 행 보조 줄은 흐립니다.
- 15의 "Git LFS를 쓰는 프로젝트라면" 접힘 제목이 회색이라 비활성처럼 보입니다. VS Code 안내 줄도 회색입니다.
- 웹(08–11)은 전체적으로 글씨가 작고 회색이 많습니다. 08 표의 "지금 원본" `4aa4393`은 아주 작은 고정폭 글씨이고, 10의 정보 패널 값과 푸터도 흐립니다. 웹은 PC에서 볼 테니 기본 글꼴을 16px 이상으로 두고, 브라우저 확대(200%)에서도 깨지지 않는지 확인해 주세요.

**터치 영역**
- 글자만 있는 링크가 작습니다. 06의 "접기", "자세히", 20의 "자세히", 13의 "분리하기", 21b의 "ngrok 설정"은 글자 높이 정도만 눌리는 것 같습니다. 48dp 높이를 확보해 주세요.
- 웹 복사 아이콘(08, 10, 11)과 09 모바일 폭의 "커밋 로그", "파일 보기"는 손가락으로 누르기에 작습니다(대략 20–24px). 모바일 폭에서는 최소 44px로 키워 주세요.
- 18, 25의 "그래도 진행"은 테두리 없는 글자 버튼입니다. 일부러 덜 눈에 띄게 한 건 이해하지만, 누르는 영역은 다른 버튼과 같은 높이여야 합니다.

**색에만 의존하는 정보**
- 19, 22, 29b의 "연결 경로별 보안" 목록은 갈색/초록/빨강 점으로 위험도를 나타냅니다. 설명 글이 있어서 완전히 의존하지는 않지만, 점의 뜻(주의/안전/위험)을 글자로 붙여 주세요. 갈색과 빨강 점은 저도 잘 구분하지 못합니다.
- 06의 변화 종류 칩은 "히스토리 바뀜"과 "태그 이동됨"이 같은 주황입니다. 글자가 있으니 문제는 아니지만, 아이콘을 넣으면(01의 배지처럼) 훑어볼 때 더 빠릅니다. 07, 08의 칩에도 아이콘이 없습니다.
- 11의 정보 패널 "LFS 파일 없음(포인터만)"은 주황 글자만으로 경고를 나타냅니다. 아이콘을 붙여 주세요.
- 23의 용량 막대는 숫자가 함께 있어서 괜찮습니다.

**레이아웃과 큰 글꼴**
- 위에서 말한 상태 줄 말줄임(02, 26, 28), FAB 겹침(04, 20, 21b, 26), 칩 줄 잘림(01–05)은 큰 글꼴에서 모두 더 나빠집니다.
