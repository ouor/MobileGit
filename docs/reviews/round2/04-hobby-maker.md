# 2차 리뷰 04 — 취미 메이커 (라즈베리파이·아두이노 홈 자동화)

리뷰어: 본업은 전기 기술자. 집 자동화 코드(ESPHome 설정, 아두이노 스케치, 파이 스크립트)를 GitHub에 올려 둔다. git은 유튜브로 배워서 clone·commit·push 정도는 하지만 force-push나 refs 같은 건 잘 모른다. Tailscale은 깔아 봤고, 포트포워딩은 공유기에서 해 봤고, ngrok은 이름만 안다.

근거로 든 화면 번호는 `docs/qa/round2/screenshots/`의 파일 번호다.

## 첫인상

- 메인 화면(01)은 "서버 켜짐 + 주소 + 스위치"가 맨 위에 있어서 공구함 전원 스위치처럼 바로 이해된다. 레포 목록도 한 줄 요약 "미러 13개 · 정상 12 · 주의 1"이 계기판 같아서 마음에 든다.
- 그런데 위에서 아래로 노란 배너가 두세 개 쌓이면(05: 배터리 배너 + 백그라운드 멈춤 배너) 레포 목록이 화면 절반 아래로 밀려난다. 첫 화면 절반이 "경고"다.
- 보안 쪽(18, 19, 20, 25, 29)은 신경 써서 만든 게 느껴지지만, 나 같은 사람은 "ngrok", "외부 공개", "외부 접속", "밖에서 접속하기", "authtoken", "토큰"이 다 같은 건지 다른 건지 헷갈렸다.

## 좋은 점

- **상태 배지가 확실하다.** "실패"(02, 빨강), "원본 없음"(03, 빨강·구름 아이콘), "지연"(04, 모래시계), "히스토리 바뀜"(01, 시계)이 아이콘·색·글자로 셋 다 구분된다. 계전기 상태 LED 보는 느낌이라 좋다.
- **"6시간 주기인데 3일째 확인 못 함"(04)** 은 최고의 문구. 숫자 두 개로 뭐가 잘못됐는지 바로 안다. 기계 점검표처럼 "기준값 vs 실측값"을 보여 준다.
- **보존 기록 화면(07)** 이 "무엇이(브랜치 삭제됨), 어디서(feature/dark-mode), 그 커밋 내용(다크 모드 배경색 초안), 지금 원본은(원본에 없음)"을 한 덩어리로 보여 준다. 누가 내 레포를 force-push로 날려도 여기서 찾으면 된다는 안심이 된다. 명령어 복사 버튼도 있다.
- **동기화 이력(06)** 에서 브랜치별로 "12e8ab8 → 4aa4393" 처럼 전후 값을 보여 주는 것. 배선 변경 전후 기록하는 습관이랑 같다.
- **clone 안내(12)** 의 "사용자 이름에 git, 비밀번호에 이 앱의 비밀번호를 넣으세요. GitHub 계정이 아니에요." 이 한 줄 덕분에 예전에 GitHub 비번 넣고 헤맨 일이 생각나서 웃었다. 꼭 필요한 문장.
- **새 로컬 레포 안내(15)** 가 명령 두 줄 + 복사 버튼 + "와이파이가 없으면 핫스팟이나 USB 테더링"까지 있어서, 작업실(와이파이 약함)에서 노트북 연결할 때 바로 쓸 수 있다. VS Code 경로 안내도 친절.
- **와이파이 경고(14)** "같은 와이파이의 다른 기기가 비밀번호를 엿볼 수 있어요. 카페 같은 공용 와이파이에서는 Tailscale을 쓰세요." 원인과 대안이 같이 있어서 좋다. 설정의 "연결 경로별 보안"(19) 신호등 표도 직관적.
- **분리 시트(16)** 의 "남는 것 / 바뀌는 것" 두 칸 구성. 차단기 내리기 전 체크리스트 같아서 안심된다. "되돌릴 수 없어요"도 분명히 써 있다.
- **재시작 뒤 ngrok 꺼짐(21, 21b)** 은 안전한 기본값이고 알림·배너 문구도 짧고 명확하다.
- **저장 공간(23)** 의 "남은 공간이 1.0 GB보다 적으면 자동 업데이트와 새 미러 받기를 멈춰요"는 차단기 정격처럼 동작 조건을 숫자로 말해 줘서 좋다.
- **웹 화면(08, 09, 10)** 이 깔끔하고 폰 폭(09)에서도 가로 스크롤 없이 카드로 바뀐다. 거실 태블릿으로 볼 때 편하겠다.

## 헷갈리거나 불편한 점

### 경고·오류 상태

1. **"외부 공개 실패"인데 "비밀번호 없이 공개돼요"(20, 29, 29b).** 빨간 배너 제목은 실패(=안 열렸다)인데 본문은 공개된다고 한다. 처음 읽고 "열린 거야 안 열린 거야?" 하고 두 번 읽었다. "지금은 안 열려 있어요. 토큰을 고치면 비밀번호 없이 열려요"처럼 지금 상태와 고친 뒤 상태를 나눠 말해야 한다. 29b에서는 "비밀번호 요구" 바로 밑에 빨간 줄이 붙어 있어서, 지금 비밀번호가 꺼져서 위험한 상태인 줄 알았다.
2. **빨간 배너 아래 요약 줄은 "모두 정상"(20).** 맨 위에서는 빨간 실패, 바로 밑에서는 초록 "모두 정상". 레포 얘기와 서버 얘기라는 건 알겠지만 한눈에는 모순처럼 보인다.
3. **배너가 쌓인다(05).** 배터리 배너와 "백그라운드 확인이 멈춘 것 같아요" 배너는 사실상 같은 원인·같은 해결(배터리 설정)인데 두 개로 따로 뜬다. 하나로 합쳐 달라.
4. **05에서 "주의 필요 13"인데 요약 줄 "미러 13개 · 정상 12 · 주의 1"이 사라지고 배너로 바뀐다.** 앞 화면들(01~04)에선 요약 줄이 있었는데 여기서는 없어져서 숫자 맞춰 보기가 어렵다. 칩은 13, 다른 화면 요약은 1 — 어느 쪽이 맞는지 처음엔 몰랐다.
5. **"주의 1"은 주황색인데 그 레포는 빨간 "실패"/"원본 없음"(02, 03, 26~28).** 요약 색과 행 색이 다르다. 실패면 요약에서도 "실패 1"로 빨갛게 나와야 할 것 같다.
6. **실패 행 문구가 잘린다(02, 26, 28).** "미러 · 업데이트 실패 · 네트워크 오류 · 방…" — 제일 중요한 "언제부터"가 잘린다. "미러 ·"는 아이콘이 이미 말해 주니 빼도 된다.
7. **원본 없음 → 네트워크 오류로 바뀌면(28) "원본 없음" 정보가 사라진다.** 원본이 삭제된 것 같다는 중요한 사실이 일시적인 네트워크 오류로 덮인다. 둘 다 보여 주거나, 최소한 상세 화면에서 "이전에 원본 없음 확인됨"을 남겨 줬으면 한다.
8. **알림에서 ngrok 실패(30)가 "서버 실행 중" 아래 회색 한 줄.** "ngrok: 토큰 확인 필요"는 너무 조용하다. 그리고 어느 토큰인지(아래 용어 참고) 모르겠다.
9. **"설정에서 authtoken을 확인하세요"(29)** — 이미 설정 화면 안인데 "설정에서"라고 한다. 바로 아래 authtoken 행을 가리키거나 버튼으로 연결해 달라.

### 보안 설정

10. **"비밀번호 요구: 읽기·쓰기 / push만 / 끄기"(19).** "push만"을 처음 봤을 땐 "push만 할 수 있다"로 읽었다. 실제 뜻은 "push할 때만 비밀번호를 묻는다"다. 설명 문구를 읽어야 알 수 있다. "push할 때만", "항상", "안 물음" 같은 이름이 내 머리엔 더 맞다. 또 "읽기·쓰기"는 무엇에 비밀번호를 거는지인데 권한 이름처럼 보인다.
11. **ngrok 경고 대화상자 두 개(18, 25)의 제목·본문이 똑같다.** 18은 "ngrok 켜기", 25는 "push만으로 바꾸기"인데 둘 다 "비밀번호 없이 외부에 공개할까요?"라서 내가 무엇을 누르다 이게 떴는지 대화상자만 봐선 모른다. 본문도 제목을 반복할 뿐이다. 25는 "외부 공개가 켜져 있어요. push만으로 바꾸면 인터넷의 누구나…" 처럼 원인을 넣어 달라.
12. **"그래도 진행" 버튼이 빨간 글씨(18, 25).** 빨간색이 눈에 제일 띄어서 오히려 누르고 싶어진다. 위험 버튼이 제일 화려한 건 반대 같다. (취소가 파란 큰 버튼인 건 좋다.)
13. **"전기적으로" 보면 와이파이 비밀번호 노출(14, 19)이 갈색/주황 점, ngrok이 빨간 점인데,** 실제로 나한테는 공유기 안 와이파이가 제일 안전하게 느껴진다. "같은 와이파이의 다른 기기" — 우리 집 IoT 기기 수십 개도 여기에 해당하는지 궁금했다. 집 와이파이는 괜찮은지 한 줄 있었으면.
14. **ngrok 영역 위치(29).** "밖에서 접속하기 (ngrok)"가 설정 맨 아래 "정보·오픈소스 라이선스" 밑에 있다. 보안상 제일 중요한 스위치가 버전 정보보다 아래에 있어서 찾다가 포기할 뻔했다. 서버 섹션 근처로 올려 달라.

### 그 밖의 동작

15. **자동 업데이트 끈 상태 설명이 화면마다 다르다.** 상세(13): "끄면 변경 확인만 하고 받지는 않아요", 설정(22): "끄면 배지만 붙어요". 같은 기능 같은데 말이 다르다. 그리고 설정 요약은 "자동 업데이트: 와이파이에서만"인데 스위치는 켬/끔 둘뿐 — "와이파이에서만"은 어디서 바꾸는지 못 찾았다.
16. **"자동 업데이트 조건은 아래 스위치에서 바꿔요"(22).** 대화상자 안에 "아래"라고 하면 대화상자 아래쪽에 스위치가 있는 줄 안다. 닫고 나서 아래라는 뜻이면 그렇게 써 달라.
17. **LFS 표시가 세 가지 말(11, 12, 15).** "LFS 파일 없음", "LFS 파일 저장 안 함", "LFS 파일 없음(포인터만)", "LFS 포인터만 올라가요". 내 3D 프린터 STL이나 회로도 PDF를 LFS로 올리는데, 결국 "폰에는 큰 파일 본체가 없다"는 한 문장이면 된다. 그리고 11에서 logo.psd가 130 B로 보이는데 클릭하면 뭐가 나오는지(포인터 텍스트?) 걱정됐다.
18. **13의 보존된 기록 "4개", 웹(08, 10)은 "3".** 다른 시점에 찍은 것일 수 있지만 같은 레포라 숫자가 다르면 불안하다.

## 문구와 용어

- **토큰이 세 종류**: "원본 접속 토큰(비공개 레포만)"(13, 24, 29), ngrok "authtoken"(18, 20, 29), 알림의 그냥 "토큰"(30). 30의 "토큰 확인 필요"는 GitHub 토큰인지 ngrok 토큰인지 모른다. "ngrok 토큰"으로 통일하고, authtoken이라는 영어는 괄호로만.
- **외부 공개 / 외부 접속 / 밖에서 접속하기 / ngrok**: 같은 기능에 이름이 네 개(18, 20, 21b, 29). 하나로 정해 달라. 나라면 "인터넷 공개 (ngrok)".
- **"히스토리 바뀜"(01, 06, 07)**: 좋은데 처음엔 "히스토리가 뭐?"였다. 06의 요약 "강제 push·삭제 감지: 3개 보존"을 보고서야 강제 push 얘기라는 걸 알았다. 배지를 길게 누르면 "원본이 강제로 덮어썼어요. 이전 커밋은 보존했어요" 같은 설명이 나오면 좋겠다.
- **"refs/archive"(07)**: "보존 기록(refs/archive)은 push로 만들거나 바꿀 수 없어요" — 나한텐 필요 없는 정보. 명령어만 복사하면 되니 이 줄은 접어 둬도 된다.
- **"분리"(13, 16)**: 처음엔 "연결 끊기"인 줄 알았다. "내 레포로 복제" 쪽이 더 바로 와닿는다. 시트 안의 "새 로컬 레포로 복제(권장)"는 좋다.
- **"방금부터"(03, 27)**: "방금부터 원본 없음"은 어색하다. "방금 확인" 이나 "10:44부터"가 낫다.
- **날짜 형식이 섞인다**: 앱 07은 "커밋 2026.10.12"와 "커밋 5일 전"을 한 화면에 섞고, 웹(08)은 "2026. 10. 20. 오후 1:15", 앱 06은 "16:35". 한 화면 안에서만이라도 통일해 달라.
- **20의 문장 끝**: "authtoken을 확인하세요" 뒤엔 마침표가 없고 다음 줄엔 있다. 사소하지만 눈에 걸린다.
- **24 영어 설명**: "This repo is for demonstration purposes only." 원본 설명이라 어쩔 수 없지만, 리스트에서 회색 작게 처리하면 덜 거슬리겠다.

## 시각과 레이아웃 문제

- **"레포 추가" 버튼이 마지막 행을 가린다**(01, 02, 04, 05, 20, 21b, 26~28). 오른쪽 화살표와 용량 숫자("10.1 KB", "3.0 K…")가 가려진다. 목록 아래쪽 여백을 버튼 높이만큼 주거나 스크롤 시 버튼을 줄여 달라.
- **요약 줄이 이상하게 줄바꿈된다(04)**: 둘째 줄이 "· 마지막 확인 1시간 전"처럼 가운뎃점으로 시작한다.
- **숫자와 단위가 갈라진다**: 06 "감지: 3 / 개 보존", 13 "확인만 해요 · 6 / 시간". 숫자랑 단위는 붙어 있어야 읽힌다(계기판에서 "6"과 "시간"이 다른 줄에 있으면 안 됨).
- **필터 칩 "주의 필요 1"이 화면 오른쪽에서 잘린다**(01~05, 14, 26~28). 가장 중요한 필터가 반쯤 잘려서 옆으로 밀어야 보인다. "주의 필요"를 첫 번째나 두 번째로 옮기거나, 0이 아닐 때만 앞으로 와도 좋겠다.
- **알림 아이콘이 기본 안드로이드 로봇(17, 21, 30)**. 앱 아이콘이 아니라서 내 알림 서랍(홈어시스턴트, 충전 제어 등)에서 mobilegit 알림을 못 알아본다. 17은 "내보내기 완료 qa 폴더에 mobilegit-backu…"로 파일 이름이 잘려 어디에 저장됐는지 끝까지 안 보인다.
- **ngrok 실패 표시(29)** 는 섹션 제목 옆에 "· 실패"를 회색으로만 쓰고, 바로 밑 빨간 줄이 다른 얘기("비밀번호 없이 공개")를 한다. 실패 자체는 회색, 가정형 경고는 빨강 — 강약이 거꾸로다.
- **13 상단**: 스크롤하면 "원본 URL" 라벨이 앱바 아래로 반쯤 잘려 "ㄹㄴ URL"처럼 보인다. 사소함.
- **24 하단**: 리스트 두 번째 카드가 하단 고정 영역에 잘려 설명 글자가 반토막 난다.

## 가장 먼저 고칠 것 3가지

1. **ngrok 실패/위험 경고를 "지금 상태"와 "고친 뒤 상태"로 나눠 쓰기 (20, 29, 29b, 30).** "실패"와 "비밀번호 없이 공개돼요"가 한 배너에 같이 있으면 지금 내 레포가 인터넷에 열려 있는지 판단할 수 없다. 이게 이 앱에서 제일 무서운 질문이다. 예: 제목 "인터넷 공개 안 됨 (ngrok 토큰 오류)", 본문 "지금은 아무도 밖에서 못 들어와요. 토큰을 고치면 비밀번호 없이 열려요 — 먼저 비밀번호 요구를 '항상'으로 바꾸세요." 알림(30)도 같은 말로.
2. **용어 통일: 토큰 3종, 외부 공개 4종, "push만" (18~20, 25, 29, 30).** "ngrok 토큰" / "원본(GitHub·GitLab) 토큰"으로 나누고, 외부 공개 이름 하나로 정하고, "push만"은 "push할 때만"으로. 두 경고 대화상자(18, 25)도 무엇 때문에 떴는지 본문에 써 주기. 겸사겸사 ngrok 설정 영역을 설정 맨 아래(정보 밑)에서 서버 섹션 옆으로 올리기(29).
3. **메인 목록 가독성: 레포 추가 버튼 겹침, 상태 문구 잘림, 칩 잘림, 배너 중복 (01, 02, 05, 26~28).** 실패 행에서 "방…"이 잘리고, "주의 필요" 칩이 잘리고, FAB가 마지막 행을 가리고, 배터리 관련 배너 두 개가 화면 절반을 먹는다. 매일 여는 첫 화면이니 여기부터. 요약 줄의 "주의" 색을 행의 빨강과 맞추는 것(02, 26)도 같이.
