## 4. 자가 진단

기준 세 가지: (1) 사용자 친화적인가 (2) 주요 기능이 한눈에 보이는가 (3) 현대적이고 깔끔한가. 실기기 스크린샷과 quick-qa 결과로 판단했다.

| # | 발견 | 기준 | 수정 |
|---|---|---|---|
| D-1 | 다크 모드에서 온보딩 제목이 검은 글자로 보이지 않음(Surface 밖의 Text가 기본 검정 사용) | 1, 3 | 앱 루트를 `Surface(background)`로 감싸 `LocalContentColor`를 `onBackground`로 |
| D-2 | 메인 대표 주소가 두 줄로 끊김(`http://192.168.31` / `.120:8080`) | 2, 3 | 큰 주소는 `host:port`만 크게 표시(복사·QR은 전체 URL), 바 전체가 복사 버튼이라 복사 아이콘 제거, 글자 19sp |
| D-3 | QR 화면(흰 바탕)에서 상태 표시줄 아이콘이 보이지 않음, URL이 IP 중간에서 줄바꿈 | 3 | QR 화면에서만 어두운 상태 표시줄 아이콘, URL 길이에 따라 글자 크기 단계 조정 |
| D-4 | 하단 고정 버튼이 제스처 바에 붙음 | 1 | `BottomAction`과 백업 하단 바에 `navigationBarsPadding` |
| D-5 | 상세 화면 탭에서 선택 안 된 탭도 파란색 | 3 | 선택 안 된 탭은 `onSurfaceVariant` |
| D-6 | 첫 받기 중인 미러가 "업데이트 없음"으로 보여 실패처럼 읽힘 | 1 | "첫 받기 전", 로컬은 "push 전" |
| D-7 | **버그**: 레포 삭제 후 상세 화면에 머물고 "rememberCoroutineScope left the composition" 문구가 노출됨 (레포가 사라지며 대화상자가 먼저 dispose되어 코루틴 취소) | 1 | 삭제 코루틴을 화면 범위 scope에서 실행. 재검증: 메인으로 돌아가고 "삭제했어요" 표시 |
| D-8 | 전체 백업에서 주요 작업(레포 선택)이 긴 복원 안내 아래로 밀림, 복원 명령 한 줄이 너무 김 | 1 | 레포 목록을 위로, 복원 안내를 아래로. 명령을 4개 블록으로 나눔 |

| D-10 | ngrok 켜기 경고 분기가 컴포지션 중 설정을 바꿈(부수 효과) | 코드 품질 | 스위치 핸들러에서 분기 |

진단 결론:
- **한눈에 보이는가**: 메인 첫 화면(스크롤 없이)에 서버 on/off 스위치와 상태, 대표 접속 주소(복사·QR), 경고 칩, 레포 목록(배지·진행률)이 모두 보인다. 추가는 FAB 하나, 드문 기능(모든 미러 업데이트, 저장 공간, 백업, 접속 기록)은 ⋮ 메뉴, 설정은 톱니 아이콘. 상세 화면은 "원본 → clone 주소 → 경고 → 관리" 순서로 자주 쓰는 것이 위에 있다.
- **사용자 친화성**: 위험 동작은 모두 확인 대화상자, 삭제는 이름 입력. 오류는 원인과 다음 행동(토큰 추가, 포트 바꾸기, 배터리 안내)을 버튼으로 함께 준다. 비어 있을 때는 다음에 할 일(세 가지 추가 방법, push 명령)을 보여 준다.
- **현대적·깔끔함**: 회색 바탕 + 흰 둥근 카드, 큰 굵은 제목, 하단 고정 큰 버튼, 해요체. 테두리·그림자 없음. 라이트/다크 모두 확인.

## 5. 남은 문제

| 항목 | 메모 |
|---|---|
| 문자열 키 이름 | `strings.xml` 키가 화면 접두어+번호(`detail_054`)라 의미가 드러나지 않는다. 영어 번역 때 의미 있는 키로 바꾸는 편이 좋다. `str()`는 애플리케이션 컨텍스트로 읽으므로 앱 내 언어 변경은 액티비티 재생성에 의존한다 |
| 코어 요청 | CR-1~4 완료·반영. CR-5(소스 zip 브랜치)는 기존 API로 해결되어 요청 없음 |
| 실기기 미확인 화면 상태 | ngrok 연결 상태 전환(유효 토큰 없음), 원본 없음·인증 필요·지연 배지의 실제 표시, 레이트리밋 대기 표시, 포트 충돌 오류, LFS·서브모듈 카드, 보존 ref 카드는 코드 경로만 있고 실제 데이터로 보지 못했다 |
| SAF "파일로 저장" | 공유 경로만 실기기 확인. 시스템 파일 선택기 경로는 미확인 |
| APK 크기 | material-icons-extended + 릴리스 R8 꺼짐(`optimization.enable = false`)으로 릴리스 APK가 커진다. R8을 켜거나 쓰는 아이콘만 벡터로 옮길 것 |
| 화면 회전·태블릿 | 세로 폰 기준으로만 확인 |
| UI 테스트 | Compose UI 자동 테스트는 없다. 실기기 확인은 수동 + quick-qa |

## 6. QA 1차 처리 (`docs/qa/round1/report.md` 4장)

| ID | 처리 | 실기기 확인 (d418f2d1) |
|---|---|---|
