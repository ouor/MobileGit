# mobilegit 안드로이드 디자인 시스템

기준: PRD v1, 사이클 1. 코드: `app/src/main/java/com/ouor/mobilegit/ui/`.
모든 화면은 아래 토큰과 공통 컴포넌트로만 만든다. 새 색·간격·모양이 필요하면 먼저 이 문서와 `theme/Theme.kt`에 추가한다.

## 1. 원칙

1. **상태가 먼저 보인다.** 서버 on/off, 접속 주소, 문제 있는 레포는 스크롤 없이 첫 화면에 있다.
2. **한 화면에 강조는 하나.** 브랜드 색(파랑)은 주요 동작과 선택 상태에만 쓴다. 나머지는 회색 계열.
3. **카드 위에 정보, 배경은 회색.** (라이트) 회색 배경 `#F2F4F6` 위에 흰 카드. (다크) `#111215` 위에 `#1B1D21` 카드. 테두리와 그림자는 쓰지 않는다.
4. **말투는 해요체, 짧게.** "~했어요", "~하세요". 오류는 원인과 다음 행동을 함께 쓴다.
5. **색만으로 구분하지 않는다** (NFR 접근성). 배지·배너는 항상 아이콘 + 글자를 함께 쓴다. 아이콘 버튼에는 모두 `contentDescription`을 단다.
6. **레포 목록이 첫 화면의 주인공이다** (1차 리뷰). 서버 카드는 한 줄 요약(상태 점 · 주소 · QR · 펼치기 · 스위치)으로 두고 자세한 정보는 펼쳐서 본다. 문제(실패 배너, 네트워크 없음)는 접혀 있어도 보인다.
7. **문제가 있을 때만 상태를 보인다.** "정상", "문제 있음 0" 같은 정상 상태 배지·칩은 그리지 않는다.
8. **토글은 긍정형.** 켜짐 = 그 기능이 동작함("자동 업데이트", "비밀번호 요구"). "~ 끄기", "~에서 제외" 같은 이름의 스위치는 만들지 않는다. 둘 이상 연관된 스위치는 세그먼트 하나로 합친다.
9. **전문 옵션은 "고급"으로 접는다** (`AdvancedSection`, 기본 닫힘). PR 브랜치, 기본 브랜치 변경 등.

|---|---|---|---|
| primary | `#3366FF` | `#7C9CFF` | 주요 버튼, 선택, 링크 |
| primaryContainer | `#E5ECFF` | `#1E2F66` | 미러 아이콘 바탕, 선택된 선택지 |

| surfaceContainerHighest | `#E8EBEF` | `#2C2F36` | 검색창 |

**상태 톤(`Tone`)**: `Neutral / Info / Success / Warning / Danger`. 각 톤은 `container`(바탕)와 `content`(글자·아이콘) 한 쌍이다. `tone(Tone.X)`로 꺼낸다.

| 톤 | 쓰는 곳 |
|---|---|
| Info | 업데이트 있음, 업데이트 중, 진행 안내 |
| Success | 서버 켜짐 점, 접근 가능, 완료, 등록됨 |
| Warning | 인증 필요, 지연, 조건 대기, 배터리, 토큰 필요 |
| Danger | 실패, 원본 없음, 외부 공개 중(ngrok), 저장 공간 부족, 비밀번호 꺼짐 |
| Neutral | LFS 누락, 메타 정보, 트리거 |

시스템 다이내믹 컬러(Material You)는 쓰지 않는다. 상태 색의 의미가 기기마다 바뀌면 안 되기 때문이다.

## 4. 간격·모양

- 간격 `Space`: 2, 4, 8, 12, 16, 24, 32dp. 화면 좌우 여백은 `Space.screen = 20dp`. 카드 사이 8~12dp, 카드 안쪽 16dp.
- 모양: extraSmall 6, small 10(보조 버튼, 코드 블록), medium 14(입력창, 배너, 주소 바), large 20(카드, 행 그룹, FAB), extraLarge 28(바텀시트).
- 터치 영역은 최소 48dp. 주요 버튼 높이 54dp, 보조 버튼 44dp.
- 떠 있는 버튼(FAB)이 있는 목록은 아래 여백을 FAB 높이 이상(96dp) 둔다. 메인 FAB는 스크롤하면 아이콘만 남는다.
- 보조 버튼은 회색이 아니라 연한 파랑(`primaryContainer`)이다. 회색 버튼은 비활성처럼 읽힌다(1차 리뷰).
- 스위치는 `appSwitchColors()`: 켜짐일 때 손잡이가 라이트·다크 모두 흰색.

## 5. 아이콘 규칙

- Material Icons **Outlined** 한 세트만 쓴다(`material-icons-extended`). Filled/Rounded를 섞지 않는다.
- 크기: 목록 앞 아이콘 20~22dp, 배지 안 13dp, 칩 16dp, 툴바 24dp.
- 의미 고정(웹도 같은 그림을 쓴다): 미러 `SyncAlt`, 로컬 `Folder`, QR `QrCode2`, 복사 `ContentCopy`, 원본 없음 `CloudOff`, 인증 `Key`, 지연 `HourglassBottom`, 외부 공개 `Public`, 저장 공간 `SdCardAlert`, 배터리 `BatteryAlert`, 내보내기 `Upload`, 분리 `CallSplit`, 삭제 `DeleteOutline`.

## 7. 화면 패턴

- 하위 화면: `AppScaffold` + `ScreenColumn`(스크롤) 또는 `LazyColumn`(목록). 주요 동작은 `BottomAction`.
- 목록 화면: 위에 설명 한 줄 → 필터 칩 → 항목 카드. 비면 `EmptyState`.
- 위험 동작(삭제, 비밀번호 끄기, 분리, ngrok 켜기)은 반드시 `ConfirmDialog`. 레포 삭제는 이름 입력까지. 삭제는 다른 동작과 같은 카드에 두지 않고 맨 아래 별도 카드.
- 레포 상세는 미러·로컬 같은 순서: 머리(종류 배지, 용량, 기본 브랜치) → PC에서 clone(주소, 명령, 계정 안내) → 원본·정보 → LFS·서브모듈·보존 기록 → 고급 → 관리 → 삭제. 미러만 "동기화 이력" 탭이 있다.
- 메인 "레포 추가"는 바텀시트 하나에 네 갈래: 미러 추가 / 계정·조직 일괄 미러 / PC 프로젝트 올리기(명령 복사) / 빈 레포 만들기. 빈 상태에도 같은 입구.
- 비밀 값은 비밀번호 입력 필드(`PasswordVisualTransformation`)로 받고, 표시는 토큰 앞 4자리만.
- QR 화면만 예외로 다크 모드에서도 항상 흰 바탕·검은 QR(프로젝터, 스캔 대비), 밝기 최대, 화면 꺼짐 방지.

## 8. 용어 (2차 리뷰 반영, 앱·웹 공통)

화면에 git 내부 용어를 그대로 쓰지 않는다. 고급 설명 안에서만 원래 이름을 괄호로 함께 쓴다. 웹 UI도 이 표를 그대로 따른다. 표에 없는 말을 새로 만들 때는 먼저 여기에 적는다.

문자열 리소스 키는 `영역_의미` 형식으로 짓는다(`main_server_on`, `detail_tab_info`, `badge_failed`). 번호 키(`detail_054`)는 쓰지 않는다(ARC-13). 여러 화면이 쓰는 말은 `common_`, 배지·상태 이름은 `badge_`·`sync_result_`·`route_`처럼 그 개념 이름을 앞에 둔다. 일괄 변경 도구: `docs/ui/tools/rename_string_keys.py`.

| 문제 상태 묶음 | **오류**(빨강: 실패·원본 없음·토큰 확인 필요), **주의**(주황: 확인 지연·히스토리 바뀜). 필터 칩은 둘을 합쳐 **주의 필요** | 문제, 경고 수 | 요약 "오류 1 · 주의 2", 칩 "주의 필요 3" |
| PR ref, refs/pull | PR 브랜치 (설명에만 `refs/pull/*`) | | |
| ref, refs | 브랜치·태그 (하나만 가리키면 "브랜치" 또는 "태그") | | "새 브랜치", "새 태그" |
| HEAD | 기본 브랜치 | | |
| 하한 | 최소 여유 공간 | | |

"미러"와 "로컬 레포"는 제품 용어로 유지한다(PRD). 처음 만나는 곳(레포 추가 시트)에 한 줄 뜻을 붙인다. 앱과 웹 모두 "레포"로 쓴다.

### 8.2 시각과 숫자

- 절대 시각: **`2026.10.25 16:35`** (24시간제, 점 구분, 연도 생략 안 함). 오늘이면 `16:35`만 써도 된다. 웹도 같은 형식(브라우저 로캘 형식 쓰지 않음).
- 상대 시각: 목록·요약의 최근성에만 ("방금", "10분 전", "3시간 전", "2일 전"). 한 카드 안에서 절대·상대를 섞지 않는다. 레포 상세(정보 카드, 업데이트·push 이력)와 보존된 기록은 절대 시각만.
- 지속 시간: "3일째", "5시간째", 1시간 안이면 "16:35부터". "방금부터"는 쓰지 않는다.
- 숫자와 단위는 붙여 쓰고 줄바꿈으로 가르지 않는다("6시간", "3개"). 앱은 어절 단위 줄바꿈(아래 8.3), 웹은 `word-break: keep-all`.
- 개수는 "브랜치 3 · 태그 2"처럼 단위마다 따로 센다. "브랜치·태그 5개"는 합계일 때만.

### 8.3 문장부호와 줄바꿈

- 행의 보조 설명(subtitle)과 칩·버튼은 마침표 없이 끝낸다. 배너 본문, 대화상자 본문, 독립 문단은 문장마다 마침표를 찍는다.
- 버튼은 결과를 말한다: "그래도 진행" 대신 "비밀번호 없이 공개", "확인" 대신 "복사해서 만들기".
- 이미 설정 화면에 있으면 "설정에서"라고 쓰지 않는다("아래 ngrok 토큰을 확인하세요").
- 앱 전체 글꼴 스타일에 어절 단위 줄바꿈(`LineBreak.WordBreak.Phrase`)을 건다(Theme.kt). 명령·주소 블록은 줄바꿈하지 않고 가로로 스크롤한다.

설계 참고(코드 복사 없음, 구조와 패턴만):
- **Now in Android** (google/nowinandroid, Apache-2.0): 디자인 시스템을 `theme` + `components`로 분리하고 화면은 그 위에서만 그리는 구조, `collectAsStateWithLifecycle` 사용 방식.
- **Tailscale Android** (tailscale/tailscale-android, BSD-3-Clause): 연결 스위치와 내 주소를 첫 카드에 두고 탭해서 복사하는 메인 화면 구성.
- **Termux / ConnectBot** (GPL-3.0 / Apache-2.0): 고정폭 주소·명령 표시 관례. GPL 코드는 보지 않고 화면 관례만 참고.
- 토스·당근 앱의 시각 언어: 회색 바탕 + 흰 둥근 카드, 큰 굵은 제목, 하단 고정 큰 버튼, 해요체.
